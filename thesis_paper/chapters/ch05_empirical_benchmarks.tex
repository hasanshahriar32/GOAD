\section{Experimental Configuration}
All experiments were conducted on a standardized benchmarking workstation using Python 3.11, PyTorch 2.3.0, and PyTorch Geometric 2.5.3. Evaluation was performed on 700 independently generated enterprise environments comprising an average of 30 nodes and 120 typed edges per domain. 

The dataset maintains a balanced class distribution across the 7 target classes: \texttt{Safe}, \texttt{ESC1}, \texttt{ESC2}, \texttt{ESC3}, \texttt{ESC4}, \texttt{ESC9}, and \texttt{ESC13} (100 environments per class). Random seeds were globally fixed to 42 for python, numpy, and torch to guarantee deterministic reproducibility.

\paragraph{Critical Analysis of Findings:}
\begin{enumerate}
    \item \textbf{Significant Advantage Over Signatures and Flat ML:} CertGraph outperforms signature heuristics (Certipy) by $+28.2\%$ in Macro-F1 ($0.9986$ vs $0.7791, p < 10^{-4}$) and flat ML by $+16.1\%$ ($0.9986$ vs $0.8600, p < 10^{-4}$).

When flat models are provided with explicit topological summary counts, they achieve comparable in-distribution F1.
\end{enumerate}

\section{The Zero-Shot Adversarial Hard Negative Benchmark}
To determine whether learned models verify topological reachability or exploit feature-level shortcuts, we executed an adversarial zero-shot benchmark:
\begin{enumerate}
    \item \textbf{Training Set:} 1,400 clean environments containing zero hard negative samples.
    \item \textbf{Test Set:} 63 out-of-distribution Hard Negative environments. Each hard negative template has ESC configuration flags enabled (e.g., \texttt{ENROLLEE\_SUPPLIES\_SUBJECT} or policy links) but has all incoming \texttt{Enroll} or DACL permissions strictly blocked. The true ground-truth label is \texttt{Safe}.
\end{enumerate}

\paragraph{Discovery of Neural Shortcut Learning:}
Under zero-shot adversarial shift, CertGraph's accuracy collapses to **1.59\%** (1/63). The GNN learned to rely on template configuration flags as predictive shortcuts during training. When presented with unseen configurations where flags indicate vulnerability but graph paths are absent, the neural model blindly predicts the vulnerability class. In contrast, the symbolic BFS baseline explicitly traverses the graph, achieving **84.13\%**.
