\section{Mathematical Formalization of Enterprise Identity Multigraphs}
To rigorously model the complex, relational authorization topology of Active Directory (AD) and Active Directory Certificate Services (ADCS), we formalize the enterprise environment as a typed, directed, heterogeneous multigraph. Unlike flat tabular databases or homogeneous network graphs that treat all entities and connections identically, a heterogeneous multigraph explicitly preserves the distinct semantic properties of different directory objects and authorization relationships.

\begin{definition}[Active Directory Heterogeneous Multigraph]
An Active Directory enterprise environment is formally defined as a 6-tuple:
\begin{equation}
G = (V, E, \mathcal{T}_V, \mathcal{T}_E, \phi_V, \psi_E)
\end{equation}
where:
\begin{enumerate}
    \item $V = \bigcup_{\tau \in \mathcal{T}_V} V_\tau$ is the finite set of all directory entities (vertices), partitioned into disjoint subsets by entity type, such that $V_{\tau_1} \cap V_{\tau_2} = \emptyset$ for all $\tau_1 \neq \tau_2$.
    \item $E \subseteq V \times \mathcal{T}_E \times V$ is the multiset of directed authorization, administrative, and enrollment relationships (edges). An edge $e = (u, r, v) \in E$ indicates a directed relationship of relation type $r$ from source entity $u$ to target entity $v$.
    \item $\mathcal{T}_V = \{\text{User}, \text{Computer}, \text{Group}, \text{Template}, \text{EnterpriseCA}\}$ represents the discrete set of node entity types ($|\mathcal{T}_V| = 5$).
    \item $\mathcal{T}_E = \{\text{MemberOf}$, $\text{Enroll}$, $\text{GenericAll}$, $\text{WriteDacl}$, $\text{WriteOwner}$, $\text{PublishedTo}$, $\text{ManageCA}$, $\text{LinksPolicy}\}$ represents the discrete set of canonical directed relation types ($|\mathcal{T}_E| = 8$).
    \item $\phi_V: V \to \mathcal{T}_V$ is an ontological type-mapping function assigning each vertex $v \in V$ its unique structural entity type $\tau(v) \in \mathcal{T}_V$.
    \item $\psi_E: E \to \mathcal{T}_E$ is a relation-mapping function assigning each directed edge $e = (u, r, v) \in E$ its canonical relation type $r \in \mathcal{T}_E$.
\end{enumerate}
\end{definition}

\begin{definition}[Network Schema and Canonical Metapaths]
The network schema of the enterprise identity multigraph is a directed meta-graph $\mathcal{S}_G = (\mathcal{T}_V, \mathcal{T}_E)$, specifying allowable directed relations between node types. A metapath $\mathcal{P}$ of length $l$ is a sequence of entity types and relation types:
\begin{equation}
\mathcal{P} = \tau_0 \xrightarrow{r_1} \tau_1 \xrightarrow{r_2} \tau_2 \xrightarrow{r_3} \dots \xrightarrow{r_l} \tau_l
\end{equation}
In Active Directory Certificate Services, privilege escalation is formalized as the existence of a valid composite metapath connecting an unprivileged security principal $s \in V_{\text{User}} \cup V_{\text{Computer}}$ to an administrative certificate issuance template $t \in V_{\text{Template}}$, followed by an authentication exchange terminating at a Tier-0 asset.
\end{definition}

\section{Node Feature Vector Spaces and Semantic Encodings}
Each vertex $v \in V$ is assigned an initial feature vector $x_v \in \mathbb{R}^{d_{\tau(v)}}$ encoding intrinsic local attributes extracted directly from LDAP directory queries and Active Directory security descriptors. Because different entity types possess distinct configuration schemas, feature spaces are typed and heterogeneous.

\subsection{Certificate Template Feature Representation}
Certificate templates are the primary targets of ADCS audits. A template vertex $t \in V_{\text{Template}}$ is assigned a 10-dimensional binary feature vector $x_{\text{Template}} \in \mathbb{R}^{10}$:
\begin{equation}
\begin{aligned}
x_{\text{Template}} = [ & f_{\text{supplies\_subject}}, f_{\text{client\_auth}}, f_{\text{any\_purpose}}, f_{\text{agent\_eku}}, f_{\text{no\_security\_ext}}, \\
& f_{\text{schema\_v1}}, f_{\text{requires\_approval}}, f_{\text{has\_policy\_link}}, f_{\text{has\_dangerous\_dacl}}, f_{\text{is\_published}} ]^T
\end{aligned}
\end{equation}
The individual binary dimensions are defined and extracted as follows:
\begin{enumerate}
    \item $f_{\text{supplies\_subject}} \in \{0, 1\}$: Extracted from the LDAP integer attribute \texttt{msPKI-}\allowbreak\texttt{Certificate-}\allowbreak\texttt{Name-}\allowbreak\texttt{Flag}. Evaluates to $1$ if the bitwise flag \texttt{CT\_FLAG\_ENROLLEE\_SUPPLIES\_SUBJECT} (\texttt{0x00000001}) is set, indicating that the enroller can specify an arbitrary Subject Alternative Name (SAN).
    \item $f_{\text{client\_auth}} \in \{0, 1\}$: Extracted from the multi-valued string attribute \texttt{pKIExtendedKeyUsage}. Evaluates to $1$ if the template includes the Client Authentication Object Identifier (OID \texttt{1.3.6.1.5.5.7.3.2}) or Smart Card Logon (OID \texttt{1.3.6.1.4.1.311.20.2.2}).
    \item $f_{\text{any\_purpose}} \in \{0, 1\}$: Evaluates to $1$ if \texttt{pKIExtendedKeyUsage} contains the Any Purpose OID (\texttt{2.5.29.37.0}) or if the attribute is empty/null, which Windows CryptoAPI interprets as valid for all cryptographic applications.
    \item $f_{\text{agent\_eku}} \in \{0, 1\}$: Evaluates to $1$ if \texttt{pKIExtendedKeyUsage} contains the Certificate Request Agent OID (\texttt{1.3.6.1.4.1.311.20.2.1}), permitting on-behalf-of enrollment.
    \item $f_{\text{no\_security\_ext}} \in \{0, 1\}$: Extracted from \texttt{msPKI-Enrollment-Flag}. Evaluates to $1$ if the flag \texttt{CT\_FLAG\_NO\_SECURITY\_EXTENSION} (\texttt{0x00080000}) is enabled, instructing the CA to omit the security extension embedding the requestor's SID.
    \item $f_{\text{schema\_v1}} \in \{0, 1\}$: Extracted from the integer attribute \texttt{msPKI-Template-Schema-Version}. Evaluates to $1$ if the schema version equals $1$, signifying a legacy Windows 2000 template susceptible to CVE-2024-49019 (EKUwu).
    \item $f_{\text{requires\_approval}} \in \{0, 1\}$: Extracted from \texttt{msPKI-Enrollment-Flag}. Evaluates to $1$ if \texttt{CT\_FLAG\_PEND\_ALL\_REQUESTS} (\texttt{0x00000002}) is set, mandating CA certificate manager intervention prior to certificate issuance.
    \item $f_{\text{has\_policy\_link}} \in \{0, 1\}$: Extracted from \texttt{msPKI-}\allowbreak\texttt{Certificate-}\allowbreak\texttt{Policy}. Evaluates to $1$ if the template references one or more Issuance Policy OIDs.
    \item $f_{\text{has\_dangerous\_dacl}} \in \{0, 1\}$: Extracted by evaluating the Discretionary Access Control List (DACL) in \texttt{nTSecurityDescriptor}. Evaluates to $1$ if any low-privileged security principal holds \texttt{GenericAll}, \texttt{GenericWrite}, \texttt{WriteDacl}, or \texttt{WriteOwner} access rights on the template object.
    \item $f_{\text{is\_published}} \in \{0, 1\}$: Evaluates to $1$ if the template name is actively listed in the \texttt{certificateTemplates} attribute of at least one operational Enterprise CA object within the Active Directory configuration partition.
\end{enumerate}

\subsection{Security Principal Feature Representations}
The security principals capable of initiating or forwarding access control operations are represented by typed feature vectors capturing administrative tiering, protocol configuration, and account state:

\begin{enumerate}
    \item \textbf{User Nodes ($x_{\text{User}} \in \mathbb{R}^6$):}
    \begin{equation}
    \begin{aligned}
    x_{\text{User}} = [ & f_{\text{is\_enabled}}, f_{\text{is\_sensitive}}, f_{\text{dont\_req\_preauth}}, \\
    & f_{\text{trusted\_for\_delegation}}, f_{\text{has\_spn}}, f_{\text{is\_admin}} ]^T
    \end{aligned}
    \end{equation}
    where $f_{\text{is\_enabled}}$ indicates whether \texttt{ACCOUNTDISABLE} is absent from \texttt{userAccountControl}; $f_{\text{is\_sensitive}}$ indicates \texttt{NOT\_DELEGATED}; $f_{\text{dont\_req\_preauth}}$ identifies accounts vulnerable to AS-REP roasting; $f_{\text{trusted\_for\_delegation}}$ flags unconstrained Kerberos delegation; $f_{\text{has\_spn}}$ flags accounts susceptible to Kerberoasting; and $f_{\text{is\_admin}} \in \{0, 1\}$ indicates membership in a Tier-0 administrative role (\texttt{adminCount} = 1).
    
    \item \textbf{Computer Nodes ($x_{\text{Computer}} \in \mathbb{R}^6$):}
    \begin{equation}
    \begin{aligned}
    x_{\text{Computer}} = [ & f_{\text{is\_enabled}}, f_{\text{is\_dc}}, f_{\text{unconstrained}}, \\
    & f_{\text{constrained}}, f_{\text{rbcd}}, f_{\text{is\_admin}} ]^T
    \end{aligned}
    \end{equation}
    where $f_{\text{is\_dc}}$ indicates a primary Domain Controller; $f_{\text{unconstrained}}$ and $f_{\text{constrained}}$ capture Kerberos delegation settings; and $f_{\text{rbcd}}$ flags resource-based constrained delegation configurations.
    
    \item \textbf{Security Group Nodes ($x_{\text{Group}} \in \mathbb{R}^2$):}
    \begin{equation}
    x_{\text{Group}} = [f_{\text{is\_tier0}}, f_{\text{is\_builtin}}]^T
    \end{equation}
    where $f_{\text{is\_tier0}} = 1$ denotes high-value administrative groups (e.g., \texttt{Domain Admins}, \texttt{Enterprise Admins}, \texttt{Schema Admins}, \texttt{Administrators}, \texttt{Account Operators}); and $f_{\text{is\_builtin}} = 1$ indicates standard well-known Windows security groups.
    
    \item \textbf{Enterprise Certificate Authority Nodes ($x_{\text{CA}} \in \mathbb{R}^3$):}
    \begin{equation}
    x_{\text{CA}} = [f_{\text{is\_root\_ca}}, f_{\text{allows\_user\_spec}}, f_{\text{enforces\_encryption}}]^T
    \end{equation}
    where $f_{\text{is\_root\_ca}}$ identifies root CAs; $f_{\text{allows\_user\_spec}}$ flags the presence of the dangerous registry setting \texttt{EDITF\_ATTRIBUTE}\allowbreak\texttt{SUBJECTALTNAME2}; and $f_{\text{enforces\_encryption}}$ identifies whether RPC interface encryption is mandated on the CA endpoint (relevant to ESC11).
\end{enumerate}

\subsection{Relational Adjacency and Canonical Reverse Relations}
For each relation type $r = (\tau_s, \text{rel}, \tau_t) \in \mathcal{T}_E$, the directed adjacency matrix $A_r \in \{0, 1\}^{|V_{\tau_s}| \times |V_{\tau_t}|}$ satisfies:
\begin{equation}
A_r[u, v] = 1 \iff (u, r, v) \in E
\end{equation}

A fundamental challenge in graph representation learning on directed identity graphs is that access control permissions flow from principals to resources (e.g., $\text{User} \xrightarrow{\text{Enroll}} \text{Template}$), whereas vulnerability reasoning requires evaluating the reverse query: \textit{"Which unprivileged principals possess an inbound access path to this template?"}

To facilitate bidirectional information exchange across the message-passing layers, we introduce formal reverse canonical relations for every directed edge type:
\begin{equation}
\forall r = (\tau_s, \text{rel}, \tau_t) \in \mathcal{T}_E \implies r^{-1} = (\tau_t, \text{rel}^{-1}, \tau_s) \in \mathcal{T}_E^{-1}
\end{equation}
The adjacency matrix for the reverse relation is the exact transpose of the forward adjacency:
\begin{equation}
A_{r^{-1}} = A_r^T
\end{equation}
The augmented relational set $\tilde{\mathcal{T}}_E = \mathcal{T}_E \cup \mathcal{T}_E^{-1}$ contains 16 directed relations, ensuring that certificate templates can gather structural context from prospective enrollers and administrative controllers during forward message passing.

CertGraph implements an inductive Heterogeneous Graph Attention Network (Hetero-GAT). Unlike homogeneous GNNs that collapse entity distinctions into a single latent space, CertGraph maintains type-specific linear projections and relation-specific multi-head attention mechanisms.

\subsection{Relation-Specific Linear Feature Projections}
Let $h_u^{(l-1)} \in \mathbb{R}^{d_{\tau(u)}^{(l-1)}}$ denote the hidden representation of node $u$ at layer $l-1$, where $h_u^{(0)} = x_u$. For each canonical relation $r = (\tau(u), \text{rel}, \tau(v)) \in \tilde{\mathcal{T}}_E$ terminating at target node $v$, source and target node representations are projected into a common relational metric space $\mathbb{R}^{d_{\text{out}}^{(l)}}$:
\begin{equation}
z_u^{(l, r)} = W_{\text{src}}^{(l, r)} h_u^{(l-1)}, \quad z_v^{(l, r)} = W_{\text{dst}}^{(l, r)} h_v^{(l-1)}
\end{equation}
where $W_{\text{src}}^{(l, r)} \in \mathbb{R}^{d_{\text{out}}^{(l)} \times d_{\tau(u)}^{(l-1)}}$ and $W_{\text{dst}}^{(l, r)} \in \mathbb{R}^{d_{\text{out}}^{(l)} \times d_{\tau(v)}^{(l-1)}}$ are learnable projection matrices. In our implementation, hidden dimensions are set to $d_{\text{hidden}} = 64$ across all layers.

\subsection{Multi-Head Relational Graph Attention}
To capture multi-faceted topological dependencies (e.g., distinguishing between direct group membership and delegated write permissions), CertGraph deploys $K$ independent attention heads per relation.

For attention head $k \in \{1, \dots, K\}$, the unnormalized attention coefficient $e_{vu}^{(k, l, r)}$ quantifying the importance of incoming source node $u$ to target node $v$ across relation $r$ is computed as:
\begin{equation}
e_{vu}^{(k, l, r)} = \operatorname{LeakyReLU} \left( \mathbf{a}_k^{(l, r) T} \left[ z_v^{(k, l, r)} \,\|\, z_u^{(k, l, r)} \right] \right)
\end{equation}
where $\mathbf{a}_k^{(l, r)} \in \mathbb{R}^{2 d_{\text{head}}}$ is a learnable relation-specific attention vector, $\|$ denotes vector concatenation, and the LeakyReLU non-linearity employs a negative slope parameter of $\alpha_{\text{leaky}} = 0.2$. The head dimension satisfies $d_{\text{head}} = d_{\text{out}}^{(l)} / K$.

To ensure comparability across nodes with varying in-degrees, attention coefficients are normalized across the set of incoming relation neighbors $\mathcal{N}_r(v) = \{u \in V_{\tau_s} \mid (u, r, v) \in E\}$ using the relational softmax function:
\begin{equation}
\alpha_{vu}^{(k, l, r)} = \frac{\exp \left( e_{vu}^{(k, l, r)} \right)}{\sum_{w \in \mathcal{N}_r(v)} \exp \left( e_{vw}^{(k, l, r)} \right)}
\end{equation}
The aggregated message for node $v$ under relation $r$ across all $K$ attention heads is obtained via concatenation:
\begin{equation}
\mu_{v, r}^{(l)} = \prod_{k=1}^K \left( \sum_{u \in \mathcal{N}_r(v)} \alpha_{vu}^{(k, l, r)} z_u^{(k, l, r)} \right)
\end{equation}
where $\|$ denotes concatenation along the channel dimension, resulting in $\mu_{v, r}^{(l)} \in \mathbb{R}^{d_{\text{out}}^{(l)}}$.

\subsection{Semantic-Level Aggregation and Residual Skip-Connections}
Because a target entity $v$ may receive incoming messages from multiple distinct relation types $\mathcal{R}_{\text{in}}(\tau(v)) = \{r \in \tilde{\mathcal{T}}_E \mid \text{target}(r) = \tau(v)\}$, CertGraph performs semantic-level aggregation via vector summation:
\begin{equation}
h_{v, \text{agg}}^{(l)} = \sum_{r \in \mathcal{R}_{\text{in}}(\tau(v))} \mu_{v, r}^{(l)}
\end{equation}

\paragraph{Additive Residual Skip-Connections:}
As established theoretically in Section~\ref{sec:theorem1_discussion}, pure neighborhood aggregation in directed acyclic or source-dominated subgraphs suffers from catastrophic representation collapse. To preserve node-specific identity features and maintain stable gradient flow, CertGraph incorporates parameterized additive residual skip-connections:
\begin{equation}
\tilde{h}_v^{(l)} = h_{v, \text{agg}}^{(l)} + W_{\text{skip}}^{(l, \tau(v))} h_v^{(l-1)}
\end{equation}
where $W_{\text{skip}}^{(l, \tau(v))} \in \mathbb{R}^{d_{\text{out}}^{(l)} \times d_{\tau(v)}^{(l-1)}}$ is a type-specific linear projection matrix.

The pre-activation state is transformed via the Exponential Linear Unit (ELU) activation function, followed by Layer Normalization and Dropout:
\begin{align}
\bar{h}_v^{(l)} &= \operatorname{ELU} \left( \tilde{h}_v^{(l)} \right) \\
h_v^{(l)} &= \operatorname{Dropout} \left( \operatorname{LayerNorm} \left( \bar{h}_v^{(l)} \right), p = 0.2 \right)
\end{align}

\subsection{Multi-Class Vulnerability Classification Head}
CertGraph stacks $L = 2$ heterogeneous graph attention layers. A 2-hop receptive field over the materialized graph is mathematically sufficient to resolve all canonical ADCS escalation paths:
\begin{enumerate}
    \item $\text{User} \xrightarrow{\text{MemberOf}} \text{Group} \xrightarrow{\text{Enroll}} \text{Template}$ (2 hops).
    \item $\text{User} \xrightarrow{\text{Enroll}} \text{Template} \xrightarrow{\text{LinksPolicy}} \text{Group}$ (2 hops).
    \item $\text{User} \xrightarrow{\text{WriteDacl}} \text{Template} \xrightarrow{\text{PublishedTo}} \text{CA}$ (2 hops).
\end{enumerate}

\paragraph{Transitive Closure of Group Nesting Hierarchy:}
A critical architectural consideration in Active Directory security graphs is the handling of deeply nested group hierarchies ($\text{User} \xrightarrow{\text{MemberOf}} \text{Group}_1 \xrightarrow{\text{MemberOf}} \dots \xrightarrow{\text{MemberOf}} \text{Group}_k$). If group relationships were maintained purely as local 1-hop edges, an $L = 2$ layer GNN would be strictly limited to evaluating 2-hop paths, failing to detect privilege escalation for users whose enrollment rights derive from groups nested at depth $k > 1$. 

To address this without increasing network depth (which would induce severe over-smoothing and gradient attenuation across sparse security graphs), CertGraph pre-expands all nested group memberships via \textbf{transitive closure materialization} during graph extraction. Following the operational semantics of the Windows Security subsystem (specifically, the Local Security Authority's evaluation of the \texttt{tokenGroups} attribute) and production graph auditing tools (such as BloodHound), our ingestion pipeline computes the reflexive transitive closure of all \texttt{MemberOf} relations prior to model ingestion:
\begin{equation}
E_{\text{MemberOf}}^* = \{(u, \text{MemberOf}, g) \mid \exists \text{ path } u \xrightarrow{\text{MemberOf}^+} g \text{ in } G\}
\end{equation}
By replacing raw nested edges with their transitive closure $E_{\text{MemberOf}}^*$, every effective group membership is collapsed into a direct 1-hop relation between the user and all ancestor groups. Consequently, $L = 2$ layers provide a comprehensive receptive field: Hop 1 resolves effective principal permissions and transitive group memberships, while Hop 2 captures template enrollment, issuance policy mapping, and CA publication edges. If transitive closure is omitted, path detection is strictly bounded by the network depth $L = 2$.

Following the second message-passing layer, we isolate the final latent representation of the target certificate template $h_t^{(L)} \in \mathbb{R}^{64}$. This embedding is forwarded to a two-layer Multi-Layer Perceptron (MLP) classification head:
\begin{align}
z_t &= \operatorname{ReLU} \left( W_1 h_t^{(L)} + b_1 \right), \quad W_1 \in \mathbb{R}^{32 \times 64}, \, b_1 \in \mathbb{R}^{32} \\
\hat{y}_t &= \operatorname{Softmax} \left( W_2 z_t + b_2 \right), \quad W_2 \in \mathbb{R}^{7 \times 32}, \, b_2 \in \mathbb{R}^{7}
\end{align}
where $\hat{y}_t \in \Delta^6$ represents the predicted probability distribution over the 7 target vulnerability classes:
\begin{equation}
\mathcal{C} = \{\text{Safe}, \text{ESC1}, \text{ESC2}, \text{ESC3}, \text{ESC4}, \text{ESC9}, \text{ESC13}\}
\end{equation}

\subsection{Objective Function with Class Imbalance Regularization}
In enterprise Active Directory environments, vulnerable certificate templates are rare relative to benign configurations. To counter class imbalance and prevent overfitting, the network is trained end-to-end by minimizing the Weighted Cross-Entropy Loss with $L_2$ weight regularization:
\begin{equation}
\mathcal{L}(\Theta) = - \sum_{i=1}^N \sum_{c=1}^{|\mathcal{C}|} \omega_c \, y_{i, c} \log \hat{y}_{i, c} + \lambda_{\text{reg}} \sum_{\theta \in \Theta} \|\theta\|_2^2
\end{equation}
where $N$ is the batch size; $y_{i, c} \in \{0, 1\}$ is the one-hot encoded ground truth; $\omega_c = \frac{N}{|\mathcal{C}| \cdot N_c}$ is the inverse class frequency weight; $\lambda_{\text{reg}} = 10^{-4}$ is the weight decay coefficient; and $\Theta$ denotes all learnable parameters ($W_{\text{src}}, W_{\text{dst}}, \mathbf{a}_k, W_{\text{skip}}, W_1, W_2$). Parameter optimization is performed using AdamW with an initial learning rate of $\eta = 10^{-3}$ and a cosine annealing learning rate schedule.

\section{Formal Algorithmic Specifications}
To ensure complete scientific reproducibility, we formalize the core execution routines of CertGraph into algorithmic specifications.

\subsection{End-to-End Layer Forward Pass}
Algorithm~\ref{alg:certgraph_layer} formalizes the computation of a single CertGraph heterogeneous attention layer with residual skip-connections and relational softmax.

\begin{algorithm}[ht]
\caption{CertGraph Heterogeneous Attention Layer Forward Pass}
\label{alg:certgraph_layer}
\begin{algorithmic}[1]
\Require Heterogeneous Multigraph $G = (V, E, \tilde{\mathcal{T}}_E)$; Input hidden states $\{h_v^{(l-1)}\}_{v \in V}$; Projection matrices $\{W_{\text{src}}^{(l, r)}, W_{\text{dst}}^{(l, r)}\}$; Attention vectors $\{\mathbf{a}_k^{(l, r)}\}$; Skip projections $\{W_{\text{skip}}^{(l, \tau)}\}$.
\Ensure Updated hidden representations $\{h_v^{(l)}\}_{v \in V}$.
\For{each canonical relation $r = (\tau_s, \text{rel}, \tau_t) \in \tilde{\mathcal{T}}_E$}
    \State Compute projected representations:
    \State \quad $z_u^{(l, r)} \gets W_{\text{src}}^{(l, r)} h_u^{(l-1)}$ for all $u \in V_{\tau_s}$
    \State \quad $z_v^{(l, r)} \gets W_{\text{dst}}^{(l, r)} h_v^{(l-1)}$ for all $v \in V_{\tau_t}$
    \For{each attention head $k \in \{1, \dots, K\}$}
        \For{each edge $(u, r, v) \in E_r$}
            \State $e_{vu}^{(k, l, r)} \gets \operatorname{LeakyReLU} \left( \mathbf{a}_k^{(l, r) T} [z_v^{(k, l, r)} \,\|\, z_u^{(k, l, r)}] \right)$
        \EndFor
        \For{each target node $v \in V_{\tau_t}$}
            \State Normalize: $\alpha_{vu}^{(k, l, r)} \gets \frac{\exp(e_{vu}^{(k, l, r)})}{\sum_{w \in \mathcal{N}_r(v)} \exp(e_{vw}^{(k, l, r)})}$
        \EndFor
    \EndFor
    \For{each target node $v \in V_{\tau_t}$}
        \State Compute head concatenation: $\mu_{v, r}^{(l)} \gets \prod_{k=1}^K \left( \sum_{u \in \mathcal{N}_r(v)} \alpha_{vu}^{(k, l, r)} z_u^{(k, l, r)} \right)$
    \EndFor
\EndFor
\For{each entity $v \in V$}
    \State Semantic aggregation: $h_{v, \text{agg}}^{(l)} \gets \sum_{r \in \mathcal{R}_{\text{in}}(\tau(v))} \mu_{v, r}^{(l)}$
    \State Additive residual skip: $\tilde{h}_v^{(l)} \gets h_{v, \text{agg}}^{(l)} + W_{\text{skip}}^{(l, \tau(v))} h_v^{(l-1)}$
    \State Non-linear activation: $\bar{h}_v^{(l)} \gets \operatorname{ELU}(\tilde{h}_v^{(l)})$
    \State Normalization \& Regularization: $h_v^{(l)} \gets \operatorname{Dropout}(\operatorname{LayerNorm}(\bar{h}_v^{(l)}), p = 0.2)$
\EndFor
\State \Return $\{h_v^{(l)}\}_{v \in V}$
\end{algorithmic}
\end{algorithm}

\subsection{Vulnerability Inference and Calibrated Risk Scoring}
Algorithm~\ref{alg:certgraph_infer} details the inference pipeline that ingests raw enterprise graphs, executes message passing, and generates calibrated risk rankings for security teams.

\begin{algorithm}[ht]
\caption{CertGraph Enterprise Vulnerability Screening and Risk Prioritization}
\label{alg:certgraph_infer}
\begin{algorithmic}[1]
\Require Enterprise Active Directory Graph $G = (V, E)$; Trained CertGraph model $\mathcal{M}_\Theta$; Risk threshold $\tau_{\text{risk}} \in [0, 1]$.
\Ensure Prioritized list of high-risk certificate templates $\mathcal{R}_{\text{alerts}}$.
\State Extract node feature tensors $\{x_v\}_{v \in V}$ from LDAP and DACL attributes
\State Construct reverse relations $r^{-1}$ for all $r \in \mathcal{T}_E$ to form augmented graph $\tilde{G}$
\State Initialize $h_v^{(0)} \gets x_v$ for all $v \in V$
\For{layer $l = 1$ to $L=2$}
    \State $\{h_v^{(l)}\}_{v \in V} \gets \operatorname{CertGraphLayerForward}(\tilde{G}, \{h_v^{(l-1)}\}_{v \in V}, \Theta^{(l)})$
\EndFor
\State Initialize empty alert queue $\mathcal{R}_{\text{alerts}} \gets []$
\For{each published template $t \in V_{\text{Template}}$}
    \State Forward embedding $h_t^{(L)}$ to classification head: $\hat{y}_t \gets \operatorname{Softmax}(W_2 \operatorname{ReLU}(W_1 h_t^{(L)} + b_1) + b_2)$
    \State Compute composite risk score: $S_{\text{risk}}(t) \gets 1.0 - \hat{y}_t[\text{Safe}]$
    \State Determine predicted vector: $c_{\text{pred}} \gets \operatorname{argmax}_{c} \hat{y}_t[c]$
    \If{$S_{\text{risk}}(t) \ge \tau_{\text{risk}}$ and $c_{\text{pred}} \neq \text{Safe}$}
        \State Append $(t, c_{\text{pred}}, S_{\text{risk}}(t), \hat{y}_t)$ to $\mathcal{R}_{\text{alerts}}$
    \EndIf
\EndFor
\State Sort $\mathcal{R}_{\text{alerts}}$ in descending order of risk score $S_{\text{risk}}(t)$
\State \Return $\mathcal{R}_{\text{alerts}}$
\end{algorithmic}
\end{algorithm}

\section{Theoretical Analysis: Intrinsic Attribute Preservation and Gradient Bounds}
\label{sec:theorem1_discussion}
A foundational theoretical contribution of this thesis is the formal proof that parameterized residual skip-connections are mathematically indispensable in heterogeneous security graph neural networks to prevent intrinsic attribute erasure and representation decay.

\begin{theorem}[Intrinsic Attribute Preservation and Gradient Lower Bounds]
\label{thm:representation_preservation}
Let $G = (V, E, \mathcal{T}_V, \mathcal{T}_E)$ be a directed heterogeneous multigraph. Consider an $L$-layer heterogeneous message-passing neural network where layer $l \in \{1, \dots, L\}$ computes hidden representations:
\begin{enumerate}
    \item \textbf{Intrinsic Feature Erasure without Skip Connections:} Under pure relational aggregation without skip connections:
    \begin{equation}
    h_v^{(l)} = \sigma \left( \sum_{r \in \mathcal{R}_{\text{in}}(\tau(v))} \bigoplus_{u \in \mathcal{N}_r(v)} \alpha_{vu}^{(l)} W_r^{(l)} h_u^{(l-1)} \right)
    \end{equation}
    the hidden representation $h_v^{(1)}$ is a function exclusively of adjacent incoming neighbor states. Consequently, for any node $v$ (including certificate templates $t \in V_{\text{Template}}$), the gradient of the immediate hidden state with respect to its own initial configuration vector $x_v$ vanishes:
    \begin{equation}
    \frac{\partial h_v^{(1)}}{\partial x_v} = \mathbf{0} \in \mathbb{R}^{d_1 \times d_0}
    \end{equation}
    causing complete erasure of intrinsic configuration attributes from the primary state representation. For source-only nodes where $d_{\text{in}}(v) = 0$, $h_v^{(l)} = \mathbf{0}$ for all $l \ge 1$.
    \item \textbf{Guaranteed Gradient Lower Bound via Residual Skips:} Introducing parameterized residual skip connections $\tilde{h}_v^{(l)} = h_v^{(l)} + W_{\text{skip}}^{(l)} \tilde{h}_v^{(l-1)}$ guarantees that the Jacobian of the representation with respect to the initial input features satisfies:
    \begin{equation}
    \left\| \frac{\partial \tilde{h}_v^{(L)}}{\partial x_v} \right\| \ge \prod_{k=1}^L \sigma_{\min}(W_{\text{skip}}^{(k)}) > 0
    \end{equation}
    where $\sigma_{\min}(W_{\text{skip}}^{(k)}) > 0$ is the minimum singular value of $W_{\text{skip}}^{(k)}$, establishing a strictly positive lower bound that prevents attribute decay across message-passing hops.
\end{enumerate}
\end{theorem}

\noindent\textit{Proof Outline.} The full mathematical derivation is provided in Appendix~\ref{proof:theorem1}. Without skip connections or self-loops, $h_v^{(1)}$ aggregates only incoming messages from external neighbors $\mathcal{N}(v)$, discarding the node's own feature tensor $x_v$. In certificate templates, this erases the 10 binary configuration flags governing PKI issuance. With residual skip projections following the GCNII framework (Chen et al., 2020)~\cite{chen2020simple}, the direct linear skip path guarantees full-rank propagation of $x_v$ to the final classification head.

\begin{corollary}[Security Attribute Preservation Corollary]
In Active Directory Certificate Services, a certificate template's exploitability depends fundamentally on its intrinsic configuration attributes (such as \texttt{ENROLLEE\_SUPPLIES\_SUBJECT} and Client Authentication EKUs). Omitting residual skip connections isolates these flags from the node's immediate layer representations, leading to severe representation decay and empirical performance collapse.
\end{corollary}

\section{Computational Complexity and Scalability Analysis}
To understand why CertGraph can screen enterprise networks in milliseconds while graph traversal tools encounter combinatorial slowdowns, we analyze its asymptotic time and space complexity:

\begin{proposition}[Computational Complexity of CertGraph Inference]
Let $G = (V, E)$ denote an enterprise identity multigraph with $|V|$ vertices, $|E|$ edges, hidden dimension $d$, and $L$ convolutional layers. The computational time complexity of a CertGraph forward pass is:
\begin{equation}
\mathcal{O} \left( L \cdot \left( |E| \cdot d + |V| \cdot d^2 \right) \right)
\end{equation}
and its auxiliary space complexity is $\mathcal{O}(|V| \cdot d + |E|)$.
\end{proposition}

\begin{proof}
For each layer $l \in \{1, \dots, L\}$:
\begin{enumerate}
    \item \textbf{Node Feature Projections:} Projecting all $|V|$ nodes across incoming relations requires $|V| \cdot d^2$ multiply-accumulate operations.
    \item \textbf{Attention Logit Computation:} Computing unnormalized attention coefficients $e_{vu}^{(k, l, r)}$ requires evaluating the dot product $\mathbf{a}_k^T [z_v \| z_u]$ for every directed edge in $E$. This evaluates in $\mathcal{O}(|E| \cdot d)$ operations.
    \item \textbf{Relational Softmax and Aggregation:} Normalizing attention coefficients and taking the weighted sum over neighbor feature vectors evaluates in $\mathcal{O}(|E| \cdot d)$ operations using sparse segment reduction primitives.
    \item \textbf{Skip Connection and Non-Linearity:} Adding the residual projection and evaluating ELU and LayerNorm requires $\mathcal{O}(|V| \cdot d)$ operations.
\end{enumerate}
Summing these stages across $L$ layers yields $\mathcal{O}(L (|E| d + |V| d^2))$. Because $L = 2$ and $d = 64$ are fixed constants, the complexity scales strictly linearly with graph volume:
\begin{equation}
\mathcal{O}(|V| + |E|)
\end{equation}
Memory space is dominated by the node state tensors $\mathbb{R}^{|V| \times d}$ and the edge index tensor $\mathbb{Z}^{2 \times |E|}$, bounded by $\mathcal{O}(|V| d + |E|)$.
\end{proof}

In contrast, deterministic graph traversal (e.g., Breadth-First Search or Cypher shortest-path queries) across all published templates exhibits worst-case computational complexity of $\mathcal{O}(|V_{\text{Template}}| \cdot (|V| + |E|))$. In densely connected enterprise forests where $|E| \gg |V|$, recursive path-finding encounters exponential path explosion along cyclic group delegation chains, whereas CertGraph executes as a sequence of highly parallelized, constant-depth GPU tensor operations.

\section{Cross-Layer Identity and PKI Provenance Graph (CIPG)}
\label{sec:cipg_methodology}
While the static heterogeneous multigraph $G = (V, E)$ defined in Section~\ref{ch:methodology} successfully captures relational authorization topologies, static models suffer from a fundamental blind spot: \textit{they assume the enterprise authorization state is static and observable at audit time.} 

In real-world advanced persistent threats (APTs) and modern ADCS abuse, sophisticated adversaries perform \textbf{transient state mutations}: an attacker with write access modifies a certificate template flag (e.g., enabling \texttt{ENROLLEE\_SUPPLIES\_SUBJECT} in ESC4) or swaps a user's \texttt{userPrincipalName} (ESC9/ESC10), submits a certificate request to the Certification Authority, obtains a forged high-privileged certificate, authenticates via Kerberos PKINIT, and subsequently rolls back the LDAP modification within seconds. When static audit tools (such as BloodHound, Certipy, or snapshot GNNs) inspect the directory after the rollback, the configuration appears completely benign, resulting in a total detection failure ($0\%$ recall).

To bridge this critical security gap and overcome static scanner vulnerabilities, we formalize the \textbf{Cross-Layer Identity and PKI Provenance Graph (CIPG)}. CIPG elevates the static identity graph into a dynamic, multiplex temporal provenance graph fusing identity entitlements, directory modifications, cryptographic issuances, and authentication exchanges into a unified causal DAG.

\subsection{Formalization of the Multiplex Provenance Graph}
\begin{definition}[Cross-Layer Identity \& PKI Provenance Graph]
The Cross-Layer Identity and PKI Provenance Graph is formally defined as a dynamic 5-tuple:
\begin{equation}
\mathcal{G} = (V, E_{\text{ent}}, E_{\text{mut}}, E_{\text{crypto}}, E_{\text{sess}})
\end{equation}
where:
\begin{enumerate}
    \item $V = V_{\text{User}} \cup V_{\text{Computer}} \cup V_{\text{Group}} \cup V_{\text{Template}} \cup V_{\text{CA}} \cup V_{\text{Cert}} \cup V_{\text{Policy}}$ represents the heterogeneous entity vertex set ($|\mathcal{T}_V| = 7$).
    \item $E_{\text{ent}} \subseteq V \times \mathcal{T}_{\text{ent}} \times V$ represents the static relational entitlement edges ($\text{MemberOf}$, $\text{Enroll}$, $\text{GenericAll}$, $\text{WriteDacl}$, $\text{PublishedTo}$).
    \item $E_{\text{mut}} \subset V_{\text{Principal}} \times \mathcal{T}_{\text{mut}} \times V \times \mathbb{R}^+ \times \Sigma^*$ represents the directed temporal stream of directory mutations extracted from Windows Security Event ID 5136:
    \begin{equation}
    e_{\text{mut}} = (u, \text{op}, v, t, \alpha, \text{val}, \text{corr\_id})
    \end{equation}
    where $u$ is the acting security principal, $\text{op} \in \{\text{ValueAdded}, \text{ValueDeleted}\}$, $v$ is the target directory object, $t$ is the event timestamp, $\alpha$ is the modified LDAP attribute name, $\text{val}$ is the attribute value, and $\text{corr\_id}$ is the directory operation correlation identifier.
    \item $E_{\text{crypto}} \subset V_{\text{Principal}} \times V_{\text{CA}} \times V_{\text{Template}} \times V_{\text{Cert}} \times \mathbb{R}^+$ represents the PKI cryptographic issuance lifecycle edges extracted from Certification Authority Event IDs 4886 (Certificate Requested) and 4887 (Certificate Issued):
    \begin{equation}
    e_{\text{crypto}} = (u, \text{ca}, t_{\text{tpl}}, c_{\text{serial}}, t, \text{req\_id}, \text{skid}, \text{SAN})
    \end{equation}
    where $u$ is the requesting identity, $\text{ca}$ is the issuing CA, $t_{\text{tpl}}$ is the invoked template, $c_{\text{serial}}$ is the issued certificate serial number, $\text{req\_id}$ is the CA request identifier, $\text{skid}$ is the X.509 Subject Key Identifier, and $\text{SAN}$ is the explicit Subject Alternative Name claim.
    \item $E_{\text{sess}} \subset V_{\text{Principal}} \times V_{\text{Computer}} \times \mathbb{R}^+ \times \mathcal{T}_{\text{auth}}$ represents authentication sessions and ticket issuances extracted from Kerberos TGT/PKINIT (Event ID 4768), TGS ticket operations (Event ID 4769), and Logon events (Event ID 4624):
    \begin{equation}
    e_{\text{sess}} = (u, h, t, \text{proto}, \text{ticket\_opt}, c_{\text{serial}}, c_{\text{thumbprint}})
    \end{equation}
    where $\text{proto} \in \{\text{PKINIT}, \text{Kerberos}, \text{NTLM}\}$, $c_{\text{serial}}$ is the authenticating certificate serial number, and $c_{\text{thumbprint}}$ is the SHA-1 certificate thumbprint.
\end{enumerate}
\end{definition}

\subsection{Causal Security Invariants}
Exploitation of Active Directory Certificate Services across all 11 ESC archetypes requires traversing causal dependencies between these distinct layers. CIPG monitors four fundamental causal security invariants:

\subsubsection{Invariant I: Two-Level Causal Invariant for $\Delta$-Rollback Detection}
An adversary attempting transient evasion modifies an object property $\alpha$ on target directory object $v$ and subsequently restores it within an audit evasion window $\Delta t_{\text{transient}}$:
\begin{equation}
\begin{aligned}
\exists e_1 = (u_1, \text{ValueAdded}, v, t_1, \alpha, \text{val}_1), \, e_2 = (u_2, \text{ValueDeleted}, v, t_2, \alpha, \text{val}_1) \in E_{\text{mut}} \\
\text{s.t. } 0 < t_2 - t_1 \le \Delta t_{\text{transient}}
\end{aligned}
\end{equation}
where $\Delta t_{\text{transient}} = 300\,\text{s}$. In enterprise networks, benign administrative typo corrections or rollback operations produce identical state-reversal cycles. To prevent high false-alarm rates ($100\%$ FPR under naive cycle detection), CIPG enforces a two-level causal classification coupling directory mutations with intermediate cryptographic activity:

\begin{enumerate}
    \item \textbf{Level 1: Confirmed Exploit Rollback ($\text{Violation}_{\text{Rollback}}^{\text{Exploit}}$):}
    A state rollback is confirmed as an active exploit if and only if an intermediate certificate request, issuance, or authentication session occurs within the causally bounded interval $[t_1 - \epsilon, \, t_2 + \epsilon]$ (where $\epsilon = 2.0\,\text{s}$ accommodates directory replication latency and clock skew):
    \begin{equation}
    \begin{aligned}
    \exists e_{\text{act}} \in E_{\text{crypto}} \cup E_{\text{sess}} \quad \text{s.t.} \quad t_{\text{act}} \in [t_1 - \epsilon, \, t_2 + \epsilon] \quad \wedge \quad \mathcal{R}(e_{\text{act}}, v) \\
    \implies \text{Verdict} = \texttt{CONFIRMED\_EXPLOIT\_ROLLBACK} \quad (\text{Severity: Critical})
    \end{aligned}
    \end{equation}
    where $\mathcal{R}(e_{\text{act}}, v)$ asserts causal relevance (i.e., certificate issuance requested against mutated template $v$ or authentication utilizing account $v$).
    
    \item \textbf{Level 2: Unexploited Configuration Drift ($\text{Warning}_{\text{ConfigDrift}}$):}
    If the rollback cycle satisfies $0 < t_2 - t_1 \le \Delta t_{\text{transient}}$ but no causally coupled intermediate cryptographic activity exists:
    \begin{equation}
    \begin{aligned}
    \nexists e_{\text{act}} \in E_{\text{crypto}} \cup E_{\text{sess}} \quad \text{s.t.} \quad t_{\text{act}} \in [t_1 - \epsilon, \, t_2 + \epsilon] \quad \wedge \quad \mathcal{R}(e_{\text{act}}, v) \\
    \implies \text{Verdict} = \texttt{UNEXPLOITED\_CONFIG\_DRIFT} \quad (\text{Severity: Audit/Informational})
    \end{aligned}
    \end{equation}
    This two-level formulation reduces the false positive rate on administrative configuration corrections from $100.0\%$ to $6.00\%$ ($3/50$ maintenance windows, $0.03\%$ overall event FPR, $93.88\%$ precision) under concurrent enterprise renewal traffic, and $0.0\%$ on isolated traces.
\end{enumerate}

\subsubsection{Invariant II: CA--KDC Schema Discontinuity and Split-Brain Transposition}
\label{sec:schema_discontinuity_math}
In enterprise Active Directory environments, certificate issuance and Kerberos PKINIT authentication execute on physically separated servers logging disjoint schemas. Let $e_{4887} \in E_{\text{crypto}}$ be a certificate issuance logged on the Certification Authority ($H_{\text{CA}}$) via Event ID 4887, and $e_{4768} \in E_{\text{sess}}$ be a Kerberos TGT request logged on the Domain Controller ($H_{\text{KDC}}$) via Event ID 4768 (with $\text{PreAuthType} = 16$).

Their respective schema projections are:
\begin{align}
\pi_{\text{CA}}(e_{4887}) &= (\text{RequestId}, \text{Requester}, \text{SKID}, \text{SubjectCN}) \\
\pi_{\text{KDC}}(e_{4768}) &= (\text{TargetUserName}, \text{PreAuthType}=16, \text{SerialNumber}, \text{Thumbprint})
\end{align}
Observe that the schema intersection is empty:
\begin{equation}
\pi_{\text{CA}}(e_{4887}) \cap \pi_{\text{KDC}}(e_{4768}) = \emptyset
\end{equation}
Event 4887 on the CA does not log the certificate serial number or SHA-1 thumbprint, while Event 4768 on the KDC does not log the requesting user, certificate template name, or CA request identifier. Consequently, single-host SIEM correlation rules cannot deterministically link the unprivileged enrollee to the privileged Kerberos session.

To resolve this discontinuity, CIPG defines the \textbf{CA Database Relational Bridge} $\mathcal{B}_{\text{CA}}$ by continuously streaming the CA Jet Database (\texttt{ICertView2} / \texttt{certutil -view}):
\begin{equation}
\mathcal{B}_{\text{CA}}: \text{SKID} \mapsto (\text{SerialNumber}, \text{Thumbprint}, \text{Requester}, \text{SubjectCN}, \text{ASN1\_SAN})
\end{equation}
which establishes the relational bijection:
\begin{equation}
\mathcal{B}_{\text{CA}}(\pi_{\text{CA}}(e_{4887}).\text{SKID}) = (\pi_{\text{KDC}}(e_{4768}).\text{SerialNumber}, \, \pi_{\text{KDC}}(e_{4768}).\text{Thumbprint})
\end{equation}

CIPG evaluates two complementary transposition invariants:
\begin{enumerate}
    \item \textbf{Invariant II-A (Standard In-Band Transposition):}
    When the Subject Alternative Name is supplied via unauthenticated request attributes (\texttt{SAN:upn=...}):
    \begin{equation}
    \begin{aligned}
    \exists e_{\text{crypto}} \in E_{\text{crypto}} \text{ s.t. } \text{SAN}(e_{\text{crypto}}) \neq \text{Requester}(e_{\text{crypto}}) \\
    \wedge \neg \text{HasManagerPrivilege}(\text{Requester}(e_{\text{crypto}}), \text{CA}) \implies \text{Violation}_{\text{Impersonation}}^{\text{InBand}}(e_{\text{crypto}})
    \end{aligned}
    \end{equation}
    
    \item \textbf{Invariant II-B (CA--KDC Split-Brain Transposition / ASN.1 Concealment):}
    When an adversary submits a PKCS\#10 CSR where the impersonation target (e.g., \texttt{upn=administrator@essos.local}) is DER-encoded inside the raw ASN.1 extension (\texttt{szOID\_SUBJECT\_ALT\_NAME2}, OID \texttt{2.5.29.17}) and sets $\text{SubjectCN} = \text{Requester}$ (e.g., \texttt{CN=khal.drogo}):
    \begin{itemize}
        \item On the CA ($e_{4887}$), $\text{Requester} = \text{SubjectCN} = \texttt{ESSOS\textbackslash khal.drogo}$ ($\text{Requester} == \text{Subject}$), blinding single-host CA detectors.
        \item In the CA Jet Database summary column, $\text{UserPrincipalName} = \texttt{"EMPTY"}$ because AD CS does not extract raw ASN.1 CSR extension blobs into database summary columns.
        \item On the KDC ($e_{4768}$), the KDC unpacks the ASN.1 extension and mints an administrative TGT for $\text{TargetUserName} = \texttt{Administrator}$.
    \end{itemize}
    CIPG catches this attack across the cryptographic bridge $\mathcal{B}_{\text{CA}}$:
    \begin{equation}
    \begin{aligned}
    \exists e_{4887} \in E_{\text{crypto}}, e_{4768} \in E_{\text{sess}} \quad \text{s.t.} \quad \mathcal{B}_{\text{CA}}(\text{SKID}(e_{4887})) = (\text{SerialNumber}(e_{4768}), \text{Thumbprint}(e_{4768})) \\
    \wedge \quad \text{Requester}(e_{4887}) \neq \text{TargetUserName}(e_{4768}) \implies \text{Violation}_{\text{SplitBrain}}^{\text{ASN1}}(\text{Attacker}, \text{Target})
    \end{aligned}
    \end{equation}
\end{enumerate}

\subsubsection{Invariant III: Cross-Host NTLM Relay Binding}
In ESC8 NTLM relay attacks against CA Web Enrollment, the incoming authentication session originates from a relayed host rather than the legitimate principal:
\begin{equation}
\begin{aligned}
\exists e_{\text{sess}} \in E_{\text{sess}}, e_{\text{crypto}} \in E_{\text{crypto}} \text{ s.t. } \text{Proto}(e_{\text{sess}}) = \text{NTLM} \\
\wedge \text{ClientIP}(e_{\text{sess}}) \neq \text{HostIP}(\text{ClaimedPrincipal}) \\
\wedge |t_{\text{sess}} - t_{\text{crypto}}| \le \Delta t_{\text{relay}} \implies \text{Violation}_{\text{Relay}}(\text{ESC8})
\end{aligned}
\end{equation}

\subsubsection{Invariant IV: OID-to-Tier-0 Group Jump}
In ESC13 attacks, issuance policies dynamically inject administrative group SIDs during authentication. CIPG verifies the bipartite linkage between issuance policy OIDs and Tier-0 groups:
\begin{equation}
\begin{aligned}
\exists e_{\text{crypto}} \in E_{\text{crypto}}, (t_{\text{tpl}}, \text{LinksPolicy}, p_{\text{oid}}) \in E_{\text{ent}}, (p_{\text{oid}}, \text{MappedGroup}, g) \in E_{\text{ent}} \\
\text{s.t. } g \in V_{\text{Tier0}} \wedge \text{Requester}(e_{\text{crypto}}) \notin g \implies \text{Violation}_{\text{PolicyJump}}(\text{ESC13})
\end{aligned}
\end{equation}

\subsubsection{Invariant V: Persistent Cryptographic Taint Propagation Automaton}
\label{sec:crypto_taint_automaton}
Single-object, fixed-window rollback invariants ($\Delta t \le 300\,\text{s}$) can be systematically evaded by sophisticated adversaries via three evasion modalities:
\begin{enumerate}
    \item \textbf{Split-Principal Collusion:} Actor $u_1$ performs the directory mutation (e.g., flipping \texttt{msPKI-Certificate-Name-Flag} via Event 5136), while a distinct unprivileged accomplice $u_2 \neq u_1$ enrolls the certificate (Event 4887), defeating naive single-actor correlation.
    \item \textbf{Indirect Group/DACL Rollbacks:} Rather than mutating the template object, the adversary temporarily injects account $u_2$ into a group $g$ possessing pre-existing enrollment permissions (Event IDs 4728/4732/4756: Member Added), requests the certificate, and promptly purges the membership (Event IDs 4729/4733/4757: Member Removed), generating zero template mutation events.
    \item \textbf{Time-Delayed (``Dormant'') Certificate Exploitation:} The adversary executes the mutation and enrollment within seconds on Day 1, but delays Kerberos PKINIT authentication ($e_{4768}$) for days or months ($t_{\text{auth}} \gg t_2 + \Delta t_{\text{transient}}$), evading all temporal windowing detectors.
\end{enumerate}

To defeat these evasion vectors with provable guarantees, CIPG defines the \textbf{Persistent Cryptographic Taint-Flow Automaton}:

\begin{definition}[Enrollment Dependency Cone]
For any certificate request $e_{\text{req}} \in E_{\text{crypto}}$ targeting template $t_{\text{tpl}}$ on behalf of requester $u_{\text{req}}$ at time $t_{\text{req}}$, its topological dependency cone $\mathcal{D}(t_{\text{tpl}}, u_{\text{req}})$ is defined as:
\begin{equation}
\mathcal{D}(t_{\text{tpl}}, u_{\text{req}}) = \{t_{\text{tpl}}, \, \text{CA}, \, u_{\text{req}}\} \cup \{g \in V_{\text{Group}} \mid (u_{\text{req}}, \text{MemberOf}, g) \in E_{\text{ent}}(t_{\text{req}})\}
\end{equation}
\end{definition}

The automaton executes across two asynchronous stages:

\paragraph{Stage A: Mint-Time Cryptographic Taint Acquisition:}
When certificate $c$ is minted at $t_{\text{req}}$ (Event ID 4887), the automaton queries whether any object $v \in \mathcal{D}(t_{\text{tpl}}, u_{\text{req}})$ underwent active mutation or membership modification within an active hysteresis window $[t_1 - \epsilon, \, t_2 + \epsilon]$ (where $t_1 \le t_{\text{req}}$ and $t_2 \ge t_{\text{req}}$ or $t_2 - t_1 \le \Delta t_{\text{transient}}$):
\begin{equation}
\exists v \in \mathcal{D}(t_{\text{tpl}}, u_{\text{req}}), \, e_1 = (u_{\text{mut}}, \text{Op}_1, v, t_1), \, e_2 = (u_{\text{mut}}, \text{Op}_2, v, t_2) \in E_{\text{mut}}
\end{equation}
If satisfied, certificate node $c$ is permanently assigned Cryptographic Taint:
\begin{equation}
\mathcal{T}(c) = \langle \text{Tainted} = \text{True}, \, u_{\text{mut}}, \, u_{\text{req}}, \, v_{\text{target}}, \, c_{\text{serial}}, \, c_{\text{skid}}, \, t_{\text{mint}} = t_{\text{req}} \rangle
\end{equation}
and indexed into the CA Relational Bridge $\mathcal{B}_{\text{CA}}$ across Join Keys $(\text{SerialNumber}, \text{Thumbprint}, \text{SKID})$.

\paragraph{Stage B: Unbounded-Horizon PKINIT Taint Trigger:}
At any future authentication timestamp $t_{\text{auth}} \in [t_{\text{req}}, \infty)$---irrespective of whether the authentication occurs 20 seconds or 200 days after the rollback closed---presentation of certificate $c$ for Kerberos PKINIT ($e_{4768}$) triggers deterministic taint resolution:
\begin{equation}
\mathcal{B}_{\text{CA}}(\pi_{\text{KDC}}(e_{4768}).\text{SerialNumber}).\text{Tainted} == \text{True} \implies \text{Violation}_{\text{Taint}}^{\text{Unbounded}}(u_{\text{mut}}, u_{\text{req}}, \pi_{\text{KDC}}(e_{4768}).\text{TargetUserName}, \Delta t_{\text{delay}})
\end{equation}
where $\Delta t_{\text{delay}} = t_{\text{auth}} - t_2$. If $u_{\text{mut}} \neq u_{\text{req}}$, the automaton attributes **Split-Principal Collusion** attributing both the mutator and enroller. If $\Delta t_{\text{delay}} > \Delta t_{\text{transient}}$, it attributes **Time-Delayed Dormant Certificate Exploitation**, achieving $100\%$ empirical recall across unbounded temporal horizons where fixed-window SIEM correlation exhibits $0\%$ recall.

\subsection{Meta-Node Provenance Routine Compression}
\label{sec:provenance_compression}
In production enterprise environments, raw provenance graphs suffer from state explosion caused by thousands of benign interactive logons, machine account authentications, and Kerberos TGS renewals (Event IDs 4624/4769). To maintain real-time graph traversal throughput, CIPG implements the \texttt{compress\_benign\_routines()} procedure based on Critical Taint Isolation and Equivalence Class Aggregation:

\begin{definition}[Critical Taint State]
Let $\tau: V \cup E \to \{0, 1\}$ denote the security taint function. An entity $x$ is marked tainted ($\tau(x) = 1$) if it participates in an unresolved invariant violation, an LDAP directory mutation $e_{\text{mut}} \in E_{\text{mut}}$, or an anomalous certificate enrollment within lookback window $W_{\text{taint}}$.
\end{definition}

\begin{algorithm}[H]
\caption{Meta-Node Routine Provenance Compression (\texttt{compress\_benign\_routines})}
\label{alg:provenance_compression}
\begin{algorithmic}[1]
\Require Provenance graph $\mathcal{G} = (V, E_{\text{ent}}, E_{\text{mut}}, E_{\text{crypto}}, E_{\text{sess}})$, taint function $\tau$, time window $W_{\text{comp}}$
\Ensure Compressed provenance graph $\mathcal{G}_{\text{comp}}$
\State $E_{\text{sess}}^{\text{comp}} \gets \emptyset$
\State Partition $E_{\text{sess}}$ into tainted set $E_{\text{tainted}} = \{e \in E_{\text{sess}} \mid \tau(e) = 1\}$ and untainted set $E_{\text{clean}} = E_{\text{sess}} \setminus E_{\text{tainted}}$
\State $E_{\text{sess}}^{\text{comp}} \gets E_{\text{sess}}^{\text{comp}} \cup E_{\text{tainted}}$ \Comment{Preserve 100\% granular fidelity for tainted events}
\State Group $E_{\text{clean}}$ into equivalence classes $\mathcal{K}$ by key $\kappa = (u, \text{ClientIP}, \text{LogonType}, h_{\text{target}})$
\For{\textbf{each} equivalence class $\mathcal{K}_{\kappa} \subseteq E_{\text{clean}}$}
    \State Sort events in $\mathcal{K}_{\kappa}$ chronologically
    \State Partition $\mathcal{K}_{\kappa}$ into consecutive non-overlapping clusters $\{C_1, C_2, \dots\}$ where $\max(t) - \min(t) \le W_{\text{comp}}$
    \For{\textbf{each} cluster $C_j$}
        \State $t_{\text{first}} \gets \min_{e \in C_j} t(e), \quad t_{\text{last}} \gets \max_{e \in C_j} t(e), \quad k \gets |C_j|$
        \State Construct meta-logon edge $e_{\text{meta}} = (u, h_{\text{target}}, t_{\text{first}}, t_{\text{last}}, \text{LogonType}, k)$
        \State $E_{\text{sess}}^{\text{comp}} \gets E_{\text{sess}}^{\text{comp}} \cup \{e_{\text{meta}}\}$
    \EndFor
\EndFor
\State \Return $\mathcal{G}_{\text{comp}} = (V, E_{\text{ent}}, E_{\text{mut}}, E_{\text{crypto}}, E_{\text{sess}}^{\text{comp}})$
\end{algorithmic}
\end{algorithm}

This routine guarantees \textbf{Zero Causal Taint Loss}: because tainted entities are strictly isolated from aggregation ($\tau(e) = 1 \implies e \notin E_{\text{clean}}$), no attacker activity is ever collapsed or obscured, while background benign logon volume is compressed by over $98.1\%$ (yielding an overall whole-network provenance compression ratio of $69.04\%$).

\subsection{Automated Minimal-Cut Interdiction Engine}
Upon invariant violation detection, CIPG traverses backward along the causal DAG to compute the minimal set cut $\mathcal{C}^* \subset E$ that permanently neutralizes the privilege escalation vector with minimum operational disruption:
\begin{equation}
\mathcal{C}^* = \arg\min_{\mathcal{C} \subseteq E} \sum_{e \in \mathcal{C}} \text{Cost}(e) \quad \text{s.t.} \quad \mathcal{G} \setminus \mathcal{C} \models \bigwedge_{i=1}^4 \text{Invariant}_i
\end{equation}
where $\text{Cost}(e)$ assigns higher weight to operational business edges (e.g., standard group memberships) and minimal weight to anomalous privilege delegations (e.g., insecure template DACLs or unconstrained enroller permissions). The engine directly emits executable, idempotent PowerShell remediation directives that revoke write ACEs, reset dangerous configuration flags, and enforce strong certificate mapping.
