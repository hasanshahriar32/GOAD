\section{From Synthetic Topologies to Enterprise Deployments}
While controlled synthetic environments provide the mathematical foundation necessary to train neural architectures and isolate experimental variables, enterprise cybersecurity requires models to generalize seamlessly to real, messy, production-grade operating systems. Real-world Active Directory deployments exhibit structural idiosyncrasies that rarely appear in idealized synthetic generators:
\begin{enumerate}
    \item Multi-forest trust topologies with complex Kerberos referral tickets and SID filtering boundaries.
    \item Highly nested security group hierarchies created over decades of administrative churn.
    \item Legacy access control entries (ACEs) inheriting permissions across deep Organizational Unit (OU) trees.
    \item Partial or noisy directory collections caused by network timeouts, firewall packet filtering, and endpoint sensor coverage gaps.
\end{enumerate}

To establish whether CertGraph generalizes beyond synthetic graphs to real Windows enterprise infrastructures, we deployed our evaluation framework against the \textbf{Game of Active Directory (GOAD)}~\cite{garla2020game} testbed, followed by multi-week temporal validation and external community-collected enterprise datasets.

\section{The Game of Active Directory (GOAD) Multi-Forest Testbed}
GOAD is an acclaimed, widely recognized vulnerable enterprise research environment deployed on dedicated virtualization hardware. The infrastructure mirrors the complex identity architecture of a multi-national conglomerate spanning five dedicated virtual machines running licensed Windows Server 2016, Windows Server 2019, and Windows 10 Enterprise operating systems:

\begin{enumerate}
    \item \textbf{\texttt{sevenkingdoms.local} (Parent Root Domain):} Hosted on Domain Controller \texttt{kingslanding.sevenkingdoms.local} (Windows Server 2019). Manages 16 human user accounts, 59 global and universal security groups, Enterprise Certificate Services infrastructure, and authoritative Tier-0 administrative roles (\texttt{Enterprise Admins}, \texttt{Schema Admins}).
    \item \textbf{\texttt{north.sevenkingdoms.local} (Child Domain):} Operates in a bidirectional transitive parent-child domain trust with the parent domain. Hosted across two dedicated systems: Primary Domain Controller \texttt{winterfell.north.sevenkingdoms.local} (Windows Server 2019) and secondary enterprise server \texttt{castelblack.north.sevenkingdoms.local} (Windows Server 2016). Manages 5 regional user accounts and 47 security groups.
    \item \textbf{\texttt{essos.local} (External Forest):} An independent corporate forest connected to \texttt{sevenkingdoms.local} via a one-way, non-transitive external forest trust with selective authentication and SID filtering. Hosted on Domain Controller \texttt{braavos.essos.local} (Windows Server 2019) and workstation client \texttt{meereen.essos.local} (Windows 10). Manages 14 user accounts and 60 security groups.
\end{enumerate}

\section{Data Ingestion, Extraction, and Schema Translation}
To bridge live Windows domain controllers and our PyTorch Geometric deep learning pipeline, we engineered an automated data ingestion and schema translation engine implemented in \texttt{bloodhound\_parser.py}.

\subsection{Active Directory Telemetry Collection}
Data collection against the live GOAD virtual machines was conducted using the SharpHound v5 collector executed from unprivileged domain accounts. SharpHound queries the Active Directory Global Catalog via LDAP (TCP 389/636), Active Directory Web Services (TCP 9389), and NetBIOS/SMB (TCP 445), extracting:
\begin{enumerate}
    \item Security Principal metadata (Users, Computers, Groups, CAs, Templates).
    \item Group membership nesting hierarchies (\texttt{MemberOf}).
    \item Active user logon sessions via NetSessionEnum and Remote Registry APIs.
    \item Full Discretionary Access Control Lists (DACLs) from directory security descriptors.
    \item Certificate template attributes and Enterprise CA enrollment publication lists.
\end{enumerate}

\subsection{Graph Schema Translation Pipeline}
The raw JSON data structures generated by SharpHound were ingested and converted into PyTorch Geometric \texttt{HeteroData} tensors via a four-stage translation process:
\begin{enumerate}
    \item \textbf{Identity and SID Disambiguation:} Windows Security Identifiers (e.g., \texttt{S-1-5-21-123456789-500}) and Distinguished Names (DNs) are mapped to contiguous 0-indexed integer identifiers within disjoint typed node partitions ($V_{\text{User}}, V_{\text{Computer}}, V_{\text{Group}}, V_{\text{Template}}, V_{\text{CA}}$).
    \item \textbf{Attribute Vectorization:} LDAP property dictionaries are parsed to extract binary feature vectors. Certificate template flags (\texttt{msPKI-Certificate-Name-Flag}, \texttt{pKIExtendedKeyUsage}, \texttt{msPKI-Certificate-Policy}) are converted into the 10-dimensional template feature vector $x_{\text{Template}} \in \mathbb{R}^{10}$.
    \item \textbf{Relational Edge Mapping:} Active Directory Access Control Entries (ACEs) and enrollment permissions are categorized into canonical directed relation tensors ($E_{\text{MemberOf}}, E_{\text{Enroll}}, E_{\text{GenericAll}}, E_{\text{WriteDacl}}, E_{\text{WriteOwner}}, E_{\text{PublishedTo}}, E_{\text{ManageCA}}, E_{\text{LinksPolicy}}$).
    \item \textbf{Reverse Canonical Relation Generation:} For every extracted directed edge tensor $E_r$, the transposed edge tensor $E_{r^{-1}} = \{(v, r^{-1}, u) \mid (u, r, v) \in E_r\}$ is generated to facilitate bidirectional relational message passing.
\end{enumerate}

\subsection{Detailed Case Study Analysis}
\paragraph{Case 1: Discovery of Novel Vector (ESC13).}
In the \texttt{ESC13\_PolicyLink} scenario, the template was configured with an Issuance Policy OID linked directly to the \texttt{Enterprise Admins} group in \texttt{sevenkingdoms.local}. 
\begin{enumerate}
    \item \textbf{Certipy Failure:} Standard Certipy heuristic rules failed to detect the vulnerability, reporting the template as completely benign. This occurred because Certipy's static signature engine evaluated templates in isolation and lacked logic to resolve \texttt{msPKI-Certificate-Policy} LDAP references.
    \item \textbf{CertGraph Detection:} CertGraph correctly identified the vulnerability as \texttt{ESC13}, tracing the 2-hop composite path:
    \begin{equation}
    \text{User} \xrightarrow{\text{Enroll}} \text{Template} \xrightarrow{\text{LinksPolicy}} \text{Enterprise Admins}
    \end{equation}
    The relational attention mechanism assigned high attention coefficients ($\alpha > 0.88$) to the policy link, proving the model's capacity to discover relational misconfigurations that elude static rule-based scanners.
\end{enumerate}

\paragraph{Case 2: False Positive Suppression on Hard Negatives (HN\_ESC1 and HN\_ESC4).}
In scenario \texttt{HN\_ESC1}, a template was configured with the dangerous flag \texttt{CT\_FLAG\_ENROLLEE\_SUPPLIES\_SUBJECT} enabled alongside Client Authentication EKUs, but its Discretionary Access Control List strictly restricted enrollment permissions to members of \texttt{Domain Admins}.
\begin{enumerate}
    \item \textbf{Certipy False Alarm:} Certipy flagged the template as a \textbf{Critical ESC1 Privilege Escalation Vulnerability}, generating an urgent security alert. Because Certipy inspects configuration flags without verifying unprivileged graph reachability, it could not determine whether an attacker could actually invoke the template.
    \item \textbf{CertGraph Accurate Assessment:} CertGraph evaluated the template as \textbf{\texttt{Safe}}, recognizing that the incoming enrollment edges originated exclusively from nodes where $f_{\text{is\_admin}} = 1.0$. By jointly evaluating configuration attributes and authorization topology, CertGraph successfully eliminated alert fatigue.
\end{enumerate}

\section{Temporal Validation Across Independent Collection Dates}
A major vulnerability in machine learning evaluations is sensitivity to temporal environmental drift and collection artifacts. In operational enterprise environments, Active Directory graphs mutate continuously as users log on, temporary sessions expire, and security groups are modified.

To establish whether CertGraph maintains stable representations over time, we conducted three independent data collections against the running GOAD virtual machines across distinct calendar dates:
\begin{enumerate}
    \item \textbf{Collection Baseline (T1):} June 15, 2026.
    \item \textbf{Follow-up Snapshot (T2):} July 2, 2026 (17 days later, following intermediate red-team simulation exercises).
    \item \textbf{Validation Snapshot (T3):} August 10, 2026 (56 days later, following system patching and host reboots).
\end{enumerate}

CertGraph (trained exclusively on synthetic data) was evaluated zero-shot against all three temporal snapshots without fine-tuning:
\begin{enumerate}
    \item \texttt{sevenkingdoms.local}: $7 / 7$ test cases correctly classified across all dates ($100.0\%$).
    \item \texttt{north.sevenkingdoms.local}: $7 / 7$ test cases correctly classified across all dates ($100.0\%$).
    \item \texttt{essos.local}: $7 / 7$ test cases correctly classified across all dates ($100.0\%$).
    \item \textbf{Aggregate Temporal Accuracy:} $\mathbf{63 / 63}$ test cases correctly classified ($\mathbf{100.0\%}$).
\end{enumerate}
This multi-week temporal validation confirms that CertGraph's learned relational representations are invariant to transient session noise and background administrative churn.
