\section{Domain Generalization: Transfer Learning on ADSynth Tiered Networks}
To verify that CertGraph is not overfitted to synthetic graph topologies, we evaluated domain transfer learning against networks generated via **ADSynth**~\cite{adsynth2024dsn}. ADSynth generates enterprise identity graphs conforming to Microsoft's official **Enterprise Administrative Tiering Model** (strictly segregating Tier-0 domain assets, Tier-1 enterprise applications, and Tier-2 workstation endpoints).

\begin{figure}[t]
    \centering
    \includegraphics[width=0.75\textwidth]{figures/tool_comparison_f1.png}
    \caption{Multi-tool comparative performance (CertGraph vs BloodHound vs Certipy) across synthetic and ADSynth realistic tiered enterprise topologies.}
    \label{fig:tool_comp}
\end{figure}

We conducted bidirectional domain adaptation experiments:
\begin{enumerate}
    \item \textbf{Train Synthetic $\to$ Test ADSynth:} CertGraph trained exclusively on synthetic topologies and evaluated zero-shot on ADSynth tiered topologies achieved Macro-F1 = $\mathbf{1.0000}$ and Accuracy = $\mathbf{1.0000}$.
    \item \textbf{Train ADSynth $\to$ Test Synthetic:} In the reverse direction, CertGraph trained on ADSynth and tested on synthetic topologies achieved Macro-F1 = $\mathbf{0.9347}$ and Accuracy = $\mathbf{0.9400}$.
    \item \textbf{ADSynth 5-Fold Cross-Validation:} Cross-validation directly on ADSynth graphs achieved Macro-F1 = $\mathbf{1.0000 \pm 0.0000}$.
\end{enumerate}

These results confirm that CertGraph learns invariant relational principles of certificate privilege escalation that generalize robustly across fundamentally distinct network architectures.

\section{Sensitivity and Robustness Analysis}
In real-world security operations, Active Directory telemetry is frequently noisy or incomplete due to network collection timeouts, firewall drops, or SharpHound session collection gaps. We evaluated CertGraph's resilience under systematic edge and feature perturbations.

\begin{figure}[t]
    \centering
    \includegraphics[width=0.85\textwidth]{figures/robustness_analysis.png}
    \caption{GNN robustness evaluation under systematic edge deletions (collection gaps), configuration feature noise (attribute corruption), and training data efficiency scaling.}
    \label{fig:robustness_fig}
\end{figure}

\subsection{Edge Perturbation (Collection Gaps)}
We simulated incomplete BloodHound collections by randomly deleting $5\%, 10\%, 20\%$, and $30\%$ of edges from the evaluation graphs. As illustrated in Figure~\ref{fig:robustness_fig}, CertGraph demonstrates exceptional resilience:
\begin{enumerate}
    \item $0\%$ edge deletion: Macro-F1 = $\mathbf{1.0000}$
    \item $10\%$ edge deletion: Macro-F1 = $\mathbf{0.9882}$
    \item $20\%$ edge deletion: Macro-F1 = $\mathbf{0.9754}$
    \item $30\%$ edge deletion: Macro-F1 = $\mathbf{0.9637}$
\end{enumerate}
Even when nearly a third of all authorization relationships are uncollected, CertGraph maintains over $96\%$ Macro-F1, demonstrating robust fault tolerance.

\subsection{Feature Noise Perturbation}
Conversely, we evaluated sensitivity to attribute corruption by randomly flipping $5\%, 10\%$, and $20\%$ of binary template configuration flags:
\begin{enumerate}
    \item $5\%$ bit flip: Macro-F1 = $\mathbf{0.8412}$
    \item $10\%$ bit flip: Macro-F1 = $\mathbf{0.7105}$
    \item $20\%$ bit flip: Macro-F1 = $\mathbf{0.5899}$
\end{enumerate}
The rapid degradation under feature corruption demonstrates that CertGraph genuinely relies on local configuration semantics in conjunction with graph topology, rather than ignoring node attributes.

\subsection{Data Efficiency and Learning Curves}
We evaluated how rapidly CertGraph converges as a function of the number of training domains:
\begin{enumerate}
    \item 40 domains: Macro-F1 = $\mathbf{0.9274}$
    \item 80 domains: Macro-F1 = $\mathbf{0.9847}$
    \item 160 domains: Macro-F1 = $\mathbf{0.9899}$
    \item 320 domains: Macro-F1 = $\mathbf{1.0000}$
\end{enumerate}
The model reaches near-optimal performance ($F1 > 0.98$) with fewer than 100 training domains, establishing its practical feasibility for enterprise deployment without requiring massive labeled datasets.
