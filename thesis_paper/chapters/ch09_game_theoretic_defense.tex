\chapter{Game-Theoretic Autonomous Defense and NP-Hardness of Edge-Severing}
\label{ch:game_theory}

\section{From Passive Auditing to Active Autonomous Defense}
While detection and risk prioritization represent the initial imperatives of cybersecurity operations, real-world Security Operations Centers (SOCs) are overwhelmed by alert fatigue. In modern cloud and hybrid identity environments, where lateral movement and privilege escalation can execute in under 30 seconds via automated tooling (e.g., Certipy/BloodHound), passive auditing is fundamentally insufficient. Modern enterprise defense demands \textbf{Autonomous Cyber Defense}—systems capable of dynamically reconfiguring the identity topology to neutralize attack paths in real time.

However, transitioning from passive GNN classification to autonomous active defense introduces severe theoretical and operational hurdles. Chief among these is the \textbf{Business Availability Constraint}: an autonomous agent could trivially neutralize all privilege escalation paths by severing all domain trust relationships, deleting all security group memberships, and revoking all certificate issuance templates. Such an action achieves total security at the cost of catastrophic denial-of-service to legitimate enterprise business operations.

\section{The Stackelberg Security Game Formulation}
To rigorously model the strategic interaction between an autonomous defender and an intelligent adversary, we formalize the defense problem as a \textbf{Bayesian Stackelberg Security Game}.

\subsection{Players and Action Spaces}
The game is played on the Active Directory multigraph $G = (V, E)$ between two asymmetric players:
\begin{enumerate}
    \item \textbf{The Defender (Leader):} The defender acts first by committing to a defensive policy $\pi_D$. The defender's action space $\mathcal{A}_D$ consists of revoking or reconfiguring authorization edges:
    \begin{equation}
    a_D = E_{\text{cut}} \subseteq E
    \end{equation}
    where each cut edge $e \in E_{\text{cut}}$ carries an operational business disruption cost $c(e) \in \mathbb{R}^+$.
    \item \textbf{The Attacker (Follower):} The attacker observes the post-mitigation graph $G' = (V, E \setminus E_{\text{cut}})$ and chooses an optimal attack trajectory $a_A = \text{Path}(s \rightsquigarrow t)$ from an initial compromised identity $s \in S_{\text{low-priv}}$ to a high-value asset $t \in T_{\text{high-value}}$.
\end{enumerate}

\subsection{Asymmetric Objective Function and Reward Regularization}
To prevent the autonomous defender from succumbing to reward hacking (catastrophic network disconnection), we formulate an asymmetric multi-objective utility function:
\begin{equation}
U_D(a_D, a_A) = R_{\text{sec}}(G') - \lambda_{\text{ops}} \sum_{e \in E_{\text{cut}}} c(e) - \beta \cdot \mathbb{I}(t \in \operatorname{Reachable}(S, G'))
\end{equation}
where:
\begin{itemize}
    \item $R_{\text{sec}}(G')$ is the security reward proportional to the reduction in attack surface blast radius.
    \item $\sum_{e \in E_{\text{cut}}} c(e)$ is the operational penalty representing business workflow disruption.
    \item $\beta$ is a catastrophic penalty applied if the attacker successfully retains any valid path to a Tier-0 asset $t \in T$.
    \item $\lambda_{\text{ops}} > 0$ is a regularization hyperparameter balancing security against business continuity.
\end{itemize}

\section{Theoretical Complexity: The NP-Hardness of Minimal-Capacity Edge-Severing}
A critical theoretical question confronting autonomous identity defense is: can an algorithm compute the optimal edge-severing strategy in polynomial time?

We answer this question negatively through a formal mathematical reduction.

\begin{theorem}[NP-Hardness of Active Directory Edge-Severing]
Given an Active Directory graph $G = (V, E)$, operational edge costs $c: E \to \mathbb{R}^+$, a set of compromised attacker sources $S \subset V$ ($|S| \ge 2$), and a set of high-value administrative targets $T \subset V$, finding the minimal-capacity set of edges $E_{\text{cut}} \subseteq E$ whose removal severs all directed paths from $S$ to $T$ while minimizing total disruption cost is NP-hard.
\end{theorem}

\noindent\textit{Proof.} The complete mathematical proof via polynomial-time reduction from the Directed Multi-way Cut problem is detailed in Section~\ref{proof:theorem2}.

\paragraph{Significance of Theorem 2:}
Theorem 2 establishes that exact, brute-force optimization of identity attack graph mitigation is computationally intractable for large enterprise graphs ($|V| > 10,000$). Consequently, autonomous defense systems cannot rely on naive combinatorial search. They strictly require \textbf{polynomial-time heuristic approximations}, validating the necessity of deep reinforcement learning and neural graph representations to guide search in continuous embedding spaces.

\section{Convergence Dynamics via Stochastic Approximation}
To train the autonomous agent within the bounded continuous state space provided by CertGraph node embeddings, we deploy Hierarchical Multi-Agent Reinforcement Learning (H-MARL). 

The stability of co-adaptive reinforcement learning (where both attacker and defender policies update simultaneously) is notoriously volatile due to environment non-stationarity. We analyze policy convergence using the **Ordinary Differential Equation (ODE) method of Stochastic Approximation**~\cite{borkar2008stochastic}.

Under the standard Robbins-Monro step-size schedule:
\begin{equation}
\sum_{k=1}^\infty \alpha_k = \infty, \quad \sum_{k=1}^\infty \alpha_k^2 < \infty
\end{equation}
the discrete-time policy iteration parameter updates $\theta_{k+1} = \theta_k + \alpha_k \nabla_\theta U(\theta_k)$ asymptotically trace the continuous trajectories of the autonomous dynamical system:
\begin{equation}
\dot{\theta}(t) = \mathbb{E}_{s, a \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a|s) Q^{\pi_\theta}(s, a) \right]
\end{equation}
Because the operational disruption penalty function $\lambda_{\text{ops}} \sum c(e)$ is strictly convex and smooth with respect to edge removal probabilities, the dynamical system admits a Lyapunov function:
\begin{equation}
\mathcal{V}(\theta) = - U_D(\theta)
\end{equation}
satisfying $\dot{\mathcal{V}}(\theta) \le 0$, formally proving that the co-adaptive training loop converges almost surely to a locally stable Stackelberg equilibrium.
