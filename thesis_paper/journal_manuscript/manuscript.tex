\title{Beyond Synthetic Accuracy: A Counterfactual Evaluation of Learned ADCS Prerequisite Detection}
\author{Shahriar Hasan, Taufiq Biswas, and Md. Ramim Hossain}
\maketitle
\begin{abstract}
High classification accuracy on synthetic security graphs does not establish that a detector resolves the authorization dependencies it is intended to model. We examine this distinction for CertGraph, a heterogeneous graph attention classifier of Active Directory Certificate Services (ADCS) configurations. First, we rebuild evaluation of its seven-class generator with disjoint input manifests, validation-only checkpoint selection, and structural tabular baselines. Across three seeds, CertGraph achieves 99.71\% mean macro-F1; a graph-count random forest reaches 99.90\%, while a post-hoc generator-matching rule reaches 100\%. Second, we construct paired positive and negative cases in an explicit, fully observed abstraction of ESC13 prerequisites. Each family changes one prerequisite and remains within one data split. CertGraph achieves 89.56\% mean accuracy and classifies both variants correctly in 79.11\% of test families, compared with 95\% and 90\% for the graph-count random forest. On remote membership interventions, all four learned baselines obtain 50\% accuracy and no completely correct pairs. We connect this result to the standard locality limitation of finite-depth message passing. Finally, we measure screening followed by symbolic verification: the neural cascade checks fewer candidates but is slower than the reference query on these small graphs. The contribution is a reproducible diagnostic protocol and bounded empirical findings, rather than a new ADCS exploit detector or evidence of production superiority. Validation against independently collected Windows environments remains necessary.
\end{abstract}
\begin{IEEEkeywords}
Active Directory Certificate Services, graph neural networks, counterfactual evaluation, synthetic benchmarks, symbolic verification.
\end{IEEEkeywords}

\section{Introduction}
ADCS security depends on interactions among certificate configuration, enrollment permissions, directory membership, and trust. The Certified Pre-Owned work documented important abuse opportunities in this infrastructure~\cite{certified}. Such dependencies make graphs a natural representation, but they also create an evaluation problem: a classifier may predict a generator's label from a few correlated attributes without resolving a principal's actual prerequisites.

This paper evaluates that problem in CertGraph, a two-layer heterogeneous graph attention model developed for template classification. We ask three questions. (RQ1) Does strong performance on its existing synthetic seven-class task establish a benefit over simple structural baselines? (RQ2) Does the model distinguish paired cases whose labels differ because one prerequisite changes? (RQ3) Does learned screening improve the cost of exact verification while retaining positives? These questions concern measurable capabilities rather than whether a particular model architecture sounds appropriate for an identity graph.

Our results motivate a narrower interpretation of high synthetic scores. Simple counts nearly solve the original task. When flag-bearing safe cases are excluded from training, both the GNN and structural tabular models generalize poorly to those cases. In the new paired task, aggregate accuracy conceals a complete failure on remote membership interventions. Screening can reduce the number of exact checks yet increase total runtime, because the exact predicate is inexpensive in this setting.

The contributions are: (i) an auditable holdout protocol with namespaced generation, input-overlap checks, saved predictions, and validation-only selection; (ii) a principal-specific paired benchmark with ten interventions and explicit abstraction boundaries; (iii) evaluation under path-length and background-size changes, including family-level metrics; and (iv) a measured comparison of learned screening with direct symbolic verification. These are contributions of this artifact and study. We do not claim the first typed ADCS graph, a new graph-attention mechanism, or a general solution to ADCS exploitability. The current evidence supports an empirical benchmark study; independent operational validation is still absent.

\section{Background and Related Work}
\subsection{ADCS analysis and existing tools}
ESC13 concerns certificate issuance policies linked to directory groups. Under suitable enrollment and authentication prerequisites, a certificate can confer authorization associated with the linked group~\cite{esc13}. Its published conditions include group-link eligibility and CA trust and publication requirements. This makes it useful for studying dependency reasoning, but a Boolean graph abstraction does not implement all Windows security semantics.

Existing tooling already addresses ADCS relationships. BloodHound models ADCS entities and attack prerequisites~\cite{bhadcs}. Certipy's documentation explicitly describes ESC13 detection and distinguishes that detection from mapping downstream group privileges~\cite{certipy}. Consequently, a locally written flag rule or path query cannot be presented as a measured Certipy or BloodHound result. No executable comparison with those products is reported here.

\subsection{Learning on security graphs}
Graph attention assigns learned weights to neighborhood messages~\cite{gat}. CertGraph applies relation-specific attention to typed graphs and adds type-specific linear skip projections. Residual mechanisms and identity mappings have substantial prior art, including GCNII~\cite{gcnii}; the use of skip projections is not, by itself, a novel contribution. Nor does adding a residual term universally guarantee a positive lower bound on a network's input Jacobian: branches can cancel, activations can have zero derivative, and projections can lose rank.

Arp et al.~\cite{arp} discuss how evaluation choices can yield misleading conclusions in security machine learning. Our experiments instantiate that concern for a specific synthetic ADCS task through independent split generation, simple baselines, and interventions on prerequisites. The resulting locality statement is standard message-passing reasoning, not a new expressivity theorem.

Defensive optimization is a related but separate problem. For example, Guo et al.~\cite{guo} study budgeted edge blocking on AD-style attack graphs. Our experiments neither evaluate autonomous permission changes nor establish disruption-aware remediation. These topics are excluded from the empirical contribution.

\section{Tasks and Abstraction Boundaries}
\subsection{Legacy seven-class task}
The existing generator assigns one template label from Safe, ESC1, ESC2, ESC3, ESC4, ESC9, and ESC13. Each sample is a small typed graph with synthetic certificate attributes and relationships. This is a mutually exclusive generator classification task, even though operational weaknesses can coexist. The term Safe means the generator's negative class; it is not a claim that a real deployment is secure.

We retain this generator to test what its reported accuracy means. A source-derived diagnostic applies a short sequence of configuration and relation checks matching its construction. This baseline is intentionally post hoc. Perfect diagnostic accuracy establishes that these generated labels are recoverable by the implemented rules on the sampled inputs; it does not validate those rules as a complete ADCS specification.

\subsection{Principal-specific ESC13 abstraction}
The second task evaluates a focal user $u$ and template $t$. Its five node types are User, Group, Template, CA, and Policy. Seven forward relation types encode user membership, nested group membership, group enrollment on a template, user enrollment on a CA, template publication, template policy association, and policy-to-group linking. Reverse relations are supplied only for neural message passing, yielding fourteen computational relation types. They do not confer reverse authorization.

The benchmark operates on resolved effective-allow relationships. It assumes eligible empty universal policy groups and a pre-resolved CA trust/availability flag. It excludes raw DACL deny precedence, inheritance resolution, SID filtering, cross-forest rules, patch-specific KDC behavior, relay, enrollment-agent chains, and incomplete collection. Approval and signature requirements are treated as unmet by the focal user. Consequently, the target is a prerequisite predicate within this abstraction, not a Windows exploitability oracle.

Let $M(u)$ be groups reachable from $u$ by one user-membership edge followed by zero or more nested-group edges. Define
\begin{align}
 A(t)&=\operatorname{Auth}(t)\land\neg\operatorname{Approval}(t)\notag\\
     &\quad\land\neg\operatorname{Signature}(t),\\
 E(u,t)&=\exists g\in M(u):\operatorname{Enroll}(g,t),\\
 C(u,t)&=\exists c:\operatorname{Published}(t,c)\notag\\
     &\quad\land\operatorname{EnrollCA}(u,c)\land\operatorname{Trusted}(c),\\
 P(t)&=\exists p,g:\operatorname{HasPolicy}(t,p)\notag\\
     &\quad\land\operatorname{Present}(p)\land\operatorname{Linked}(p,g)\notag\\
     &\quad\land\operatorname{HighValue}(g).
\end{align}
The binary label is
\begin{equation}
 y(u,t)=A(t)\land E(u,t)\land C(u,t)\land P(t).
 \label{eq:predicate}
\end{equation}
HighValue is an input annotation of the authorization objective; its correctness is assumed rather than learned. This assumption deliberately separates resolving prerequisites from inferring the business importance of a group.

\subsection{Differential reference checking}
The primary reference uses queue-based membership traversal followed by relation intersections. A second implementation computes Boolean matrix transitive closure and evaluates the predicate independently. Both agree on every generated case in the reported paired experiment. Additional tests remove arbitrary edges and compare their answers, so agreement is not checked solely on untouched generator outputs.

These checks can expose coding errors in either implementation. They cannot detect a shared mistake in the predicate, and they do not establish correspondence with Windows behavior. The reference's 100\% result is a consistency result because it defines the labels. Treating that score as an independent detection achievement would be circular.

\section{Counterfactual Construction}
Each family contains a positive case and a negative variant. Two users connect to symmetric membership chains. One chain has enrollment on the target template; the other has enrollment on a distractor. Both templates share a CA and issuance policy. Background groups contain optional cycles in a disconnected component. A shared random permutation of node indices is applied to both variants. Family identifiers, variant names, mutation identifiers, and labels are stored for auditing but are not model features.

Ten intervention types are equally represented in the mixed test sets: exchange the users' chain memberships; move the target enrollment grant to the distractor; remove focal CA enrollment; remove target publication; disable authentication; require approval; require a signature; remove the target policy association; remove the linked group's high-value annotation; or disable CA trust. Each changes one semantic prerequisite. Some require rewiring several edges, so ``one intervention'' does not mean exactly one edge edit. The privilege annotation intervention changes the stated target objective rather than simulating an ACL repair.

Most interventions change a directly visible attribute or count. The membership exchange is deliberately different: it preserves the template configuration and relation degree counts while changing which user can reach the enrolling group. Thus the mixed benchmark includes both easy local evidence and a controlled relational ambiguity. It is not a balanced survey of all possible ADCS configurations.

\subsection{Splits and shifts}
For each seed, training contains 300 families (600 graphs) and validation contains 100 families (200 graphs). Each of the IID, long-path, and larger-graph tests has 150 families (300 graphs). A targeted remote-membership test has 100 families (200 graphs). Families never cross splits. Training and IID depths contain zero to three group-to-group edges per chain; the long-path and remote tests contain five to eight. The larger-graph test increases background groups from 8--32 to 128--256 while retaining training-range depths.

Independent namespace strings are included in deterministic generation seeds. We also hash model-observable node tensors, edge indices, and target indices to reject exact cross-split duplicates. This is an exact representation check, not graph-isomorphism deduplication. Repeated motifs and isomorphic local neighborhoods are expected, including by design in the remote test. Consequently, IID means held-out families from the same construction, not independent organizations or novel security mechanisms.

\section{Models, Selection, and Metrics}
\subsection{Compared methods}
CertGraph has two heterogeneous attention layers with relation outputs summed by node type. The first layer uses four heads of width 32 (128 concatenated channels); the second uses one head of width 16. Type-specific linear skips accompany both layers. ReLU and dropout of 0.2 are used, followed by a 16-to-16-to-output classifier. There are seven outputs for the legacy task and two for the prerequisite task. Lazy parameters are initialized before constructing the optimizer.

Feature MLP uses only target template attributes. Graph-count MLP and Graph-count RF add direct structural summaries, without membership closure. On the paired task these include trusted-CA and high-value-group counts, target enrollment/publication/policy counts, focal CA enrollment count, policy-link count, and nested-membership edge count. These engineered features give the tabular methods useful global summaries; they are not identical to the GNN's finite receptive field. Their purpose is to test whether a simpler representation suffices, not to claim information-equivalent architectures.

The MLP has two hidden layers of width 32, with ReLU and dropout of 0.2. The random forest has 200 trees with otherwise library defaults. The paired reference receives the complete abstract graph. For the legacy task, we additionally retain the historical direct-edge rules under that descriptive name and add the post-hoc generator diagnostic. Neither is an external-tool execution.

\subsection{Training and holdouts}
All runs use seeds 11, 29, and 47. The GNN uses Adam, learning rate 0.005, weight decay $10^{-4}$, batches of 64 graphs, at most 80 epochs, and patience 15. Checkpoints minimize validation negative log-likelihood; test scores never select an epoch or seed. MLPs use Adam at 0.01, the same weight decay, at most 250 full-batch epochs, and patience 35. Scaling statistics are fitted on training inputs only, with each standard deviation floored at one. Hyperparameters are fixed across reported runs; there is no exhaustive architecture search.

Each legacy run contains 700 training, 210 validation, and 350 test graphs. In the mixed-training condition, all splits contain generator hard negatives. In the no-HN-training condition, training and validation exclude them but testing includes them. The two conditions have separately generated datasets, including test sets. Their difference is descriptive rather than a matched-sample causal estimate of the training intervention.

\subsection{Reported quantities}
For seven classes we report macro-F1, with the label set fixed across runs. We separately report specificity for flag-bearing safe examples. For binary cases we save accuracy, macro-F1, recall, specificity, precision, average precision, and confusion matrices. A pair is completely correct only if both its positive and negative variant are classified correctly:
\begin{equation}
 B=\frac{1}{N}\sum_{i=1}^{N}
 \mathbf{1}[\hat y_i^+=1\land\hat y_i^-=0].
\end{equation}
The family, not its two correlated rows, is the resampling unit for saved percentile bootstrap intervals (2,000 resamples). Tables summarize three-seed means and sample standard deviations; these are not population confidence intervals. Three runs and restricted motifs cannot support broad statistical generalization. Zero observed variance can arise because all seeds reproduce the same systematic error.

CertGraph averages 89.56\% case accuracy on IID families, but only 79.11\% complete-pair correctness. The count MLP and forest obtain 95\% and 90\%, respectively (Tables~\ref{tab:counterfactual} and~\ref{tab:pairs}). The feature MLP reaches 65\% accuracy by resolving the three template-attribute interventions. Its 30\% pair correctness more directly exposes the limited set of prerequisites it distinguishes.

The per-intervention records show 50\% GNN accuracy on both membership exchange and template-enrollment removal in all three IID runs. Eight intervention types are perfectly classified in two runs; the third also makes errors on the privilege-annotation intervention. This diagnoses the observed errors without attributing every failure to architectural locality.

The long-path mixture does not materially lower aggregate accuracy: many interventions remain locally visible even when the membership chain is longer. Thus a high score on a mixture of long-path graphs is insufficient evidence of long-range reasoning. On the targeted remote-membership set, every learned method obtains 50\% accuracy and 0\% complete-pair correctness. All predict the positive class for both variants under the default decision rule. Figure~\ref{fig:paired} contrasts those metrics with the mixed tests.

Increasing only disconnected background size reduces the count MLP's mean accuracy to 67.56\%, while the count forest remains at 95\%. The GNN averages 89.67\%. The background edge count is included in the engineered feature vector, so this shift tests extrapolation of that representation as well as the classifier. It is not evidence that all tabular learners fail on larger directories, nor a scalability test on enterprise data.

\subsection{Locality explains a controlled failure}
\begin{proposition}[Standard message-passing locality]
Consider a deterministic $L$-layer message-passing model whose updates use only a node's current representation and typed incoming-neighbor messages, with no global pooling or global structural encoding. If two targets have isomorphic feature- and relation-preserving depth-$L$ computation neighborhoods, their output logits are equal. Nodewise residual projections do not change this statement.
\end{proposition}
\begin{proof}
Corresponding depth-zero representations are equal by assumption. If corresponding representations at depth $k$ are equal, each corresponding node receives the same multiset of typed messages at the next layer. Shared update and aggregation functions therefore produce equal representations. Nodewise projections preserve equality. Induction to depth $L$, followed by a shared classifier, gives equal logits.
\end{proof}
For paired opposite labels satisfying the proposition, the same deterministic decision cannot classify both correctly. Its case accuracy over that pair is exactly one half. The remote membership construction supplies such pairs for the evaluated two-layer model; a regression test verifies equal evaluation logits on a representative pair before training. This is a designed limitation of the available representation, not a universal impossibility result for GNNs. Greater depth, principal-conditioned path summaries, global mechanisms, or precomputed closure change the assumptions and require separate evaluation.

\subsection{RQ3: Does screening accelerate verification?}
For each learned method, we set the screening threshold to the minimum positive validation score, retaining all observed validation positives. This is a permissive empirical operating point, not a guarantee on unseen positives. The final decision is the screen decision conjoined with the exact reference predicate. A cheap comparison first tests the necessary template flags and then runs the same reference.

\input{generated/cascade.tex}
On IID tests, CertGraph screening passes 55\% of candidates to verification and retains all observed positives. Its mean corpus time is 407.31~ms, compared with 2.89~ms for reference-only evaluation (Table~\ref{tab:cascade}). Count-MLP screening also checks 55\%, but takes 5.15~ms. The RF cascade has mean recall 99.78\%, showing that retaining every validation positive does not ensure retention on a test set. The cheap necessary-flags cascade checks 85\% and takes 3.64~ms; the reference already short-circuits on those flags, explaining why an external prefilter need not help.

These timings are in-memory microbenchmarks over 300 small graph cases. They include model batching or feature extraction and selected verification, but exclude raw collector ingestion, network transfer, and persistent graph-database indexing. Each callable is warmed up; we use the median of five reference/flag repetitions and three learned-pipeline repetitions per seed. CPU contention and the small number of repeats limit precise performance inference. The data nevertheless provide no measured acceleration benefit from the tested GNN cascade in this setting.

If $S$ is the screening decision and $V$ is the verifier decision, the cascade accepts only when $S\land V$. Consequently,
\begin{equation}
 \Pr(S\land V=1\mid Y=1)\leq\Pr(S=1\mid Y=1).
\end{equation}
An exact verifier cannot recover a positive that screening discards. Zero false positives follow by construction only when the verifier is sound for the target labels; here that statement is restricted to our prerequisite predicate. It is not a zero-error guarantee for operational ADCS.

\section{Validity, Reproducibility, and Scope}
\subsection{Internal validity}
Saved manifests and namespace separation address exact train--test overlap. Validation-only selection avoids choosing checkpoints by test performance. Checkpoints, per-case scores, confusion matrices, training histories, source hashes, and package versions are retained. The reference differential tests address implementation consistency. These controls do not remove specification bias, generator shortcuts, or the information differences among local, count-based, and full-graph methods.

The interventions were designed after reviewing the legacy system, so this is an exploratory diagnostic study rather than a preregistered confirmatory experiment. Model settings were fixed for the reported runs, and all completed default seeds are included. Pair-preserving construction is stronger than independently drawing positive and negative graphs for the stated diagnostic question, but the restricted family templates make many cases much simpler than actual environments.

\subsection{External validity}
No result in this paper is independently labeled by certificate enrollment and authentication outcomes on Windows. Policy-group eligibility and trust are assumed inputs, and effective enrollment is already resolved. The generators do not model all authorization conflicts, collection errors, overlapping ESC conditions, or realistic class prevalence. In particular, ``negative'' means that this one predicate is false, not that the environment has no exploitable path.

Existing GOAD-based artifacts in the workspace combine collected directory topology with synthetic certificate configurations. Such topology scaffolds do not constitute independent ADCS validation and are not counted as additional deployment environments here. Likewise, a locally implemented tiered generator inspired by another project is not an evaluation of that upstream generator. Claims about enterprise robustness require separate data provenance and independently checked labels.

\subsection{Reproduction artifact}
The revision stores six legacy runs and three paired-task runs under \texttt{results/publication\_validation}. A table builder reads completed result files, verifies the expected seed/condition coverage, and produces the manuscript tables and plot. Predictions retain input hashes or family identifiers for reanalysis. Paired cases are distributed as compressed JSON alongside tensor-model checkpoints. Source fingerprints and package versions record the execution environment; the reported runs use Python 3.11.11, PyTorch 2.12.0 CPU, and PyTorch Geometric 2.8.0, with two PyTorch threads.

The accompanying protocol specifies how independent Windows cases and real tool runs should be recorded. Those records are currently absent. Thus the artifact is reproducible synthetic evidence with a concrete external-validation plan, not a completed production benchmark. Historical outputs are preserved separately so that corrections do not erase the provenance of earlier claims.

\section{Implications and Future Validation}
The results suggest three evaluation requirements for learned authorization analysis. First, compare against direct rules and inexpensive structural features before attributing accuracy to message passing. Second, report prerequisite-specific and complete-pair performance: mixture accuracy can obscure failure on the relational dependency motivating the model. Third, measure the full screening-plus-verification path and compare it with a short-circuiting exact predicate. Fewer candidates are not themselves evidence of lower cost.

A stronger follow-up should collect independent ADCS configurations, freeze labels before model evaluation, and retain evidence of effective permissions, published templates, trust, policy links, and observed outcomes. The same authorized snapshots should support version-pinned Certipy and BloodHound evaluations, with clearly defined output-to-task mappings. Splits should separate environment and time, rather than only generator seeds. Multiple prerequisite interventions should include inheritance conflicts, missing data, alternate paths, and overlapping weaknesses.

Where a fully observed predicate is cheap, this study supports retaining exact verification. A useful learned extension would need a different demonstrated advantage, such as calibrated ranking under incomplete observations or amortized work at measured scale. Such claims require new experiments; the present data do not establish them. Autonomous remediation additionally requires valid action semantics, business constraints, and outcome measurements, and remains outside this paper.

\section{Conclusion}
The reconstructed evaluation distinguishes synthetic label prediction from prerequisite reasoning. CertGraph's near-perfect legacy score is matched by simpler structural baselines, while paired interventions reveal unresolved membership dependencies. A learned screening cascade reduces checks but provides no runtime advantage over the tested exact reference on small in-memory graphs. The resulting artifact provides auditable splits, paired cases, differential checks, and measured failure modes. Its findings are bounded by the abstraction and await independent Windows validation before supporting operational detection claims.
