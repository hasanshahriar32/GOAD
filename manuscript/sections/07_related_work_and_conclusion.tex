\section{Related Work, Discussion, and Conclusion}
\label{sec:related_conclusion}

\subsection{Related Work}

\paragraph{Active Directory and PKI Security:}
Automated privilege escalation analysis on identity graphs originated with BloodHound~\cite{robbins2017bloodhound}, which models Windows domain objects using graph databases and Dijkstra-based shortest-path traversal. SpecterOps~\cite{specterops2021certified} expanded the attack surface to Public Key Infrastructure by formalizing certificate template misconfigurations (ESC1--ESC8), later extended through ESC13. Open-source audit tools such as Certipy~\cite{certipy2021} and Lynt automate template querying via LDAP. However, these tools operate strictly on periodic static snapshots, leaving them fundamentally blind to temporal rollback attacks ($\text{SHA-256}(\mathcal{G}_{t_0}) = \text{SHA-256}(\mathcal{G}_{t_3})$) and incapable of correlating split-actor certificate issuances with downstream Kerberos PKINIT authentications.

\paragraph{Graph Neural Networks in Cyber Defense:}
GNNs have been applied to vulnerability discovery, binary analysis, and intrusion detection~\cite{kipf2017semi,velickovic2018graph,guo2022practical,vasquez2024identity}. In access control multigraphs, however, existing architectures suffer from representation collapse and feature erasure (Theorem~\ref{thm:theorem1}). While additive skip connections preserve initial feature gradients, we showed that they induce severe inductive shortcut collapse, reducing hard-negative accuracy to $1.59\%$. CertGraph's Multiplicative Bilinear Gating provides the first formal mechanism to enforce that attribute signals cannot bypass multi-hop reachability verification.

\paragraph{Provenance Graphs and Causality Tracking:}
System provenance techniques (e.g., CamFlow~\cite{pasquier2017practical}, Unicorn~\cite{han2020unicorn}, and NodeMerge~\cite{hassan2020tactical}) track causal relationships across kernel-level system calls (processes, files, sockets). However, OS-level provenance graphs operate below the identity abstraction layer, completely lacking visibility into LDAP directory modifications, ASN.1 certificate extensions, and Kerberos ticket issuance. CIPG extends provenance principles into enterprise identity systems, introducing cryptographic invariants that bridge Windows security audit logs and CA transactional databases.

\paragraph{Game-Theoretic Interdiction and Access Control Defense:}
Network interdiction models have been extensively studied in game theory and physical infrastructure defense~\cite{tambe2011security,dahlhaus1994multiterminal,garg1994multiway}. In identity security, Guo et al.~\cite{guo2022practical,guo2023scalable} analyzed shortest-path interdiction on BloodHound graphs. Theorem~\ref{thm:nphardness} advances this theoretical foundation by proving that Multi-Principal Access Interdiction (MPAI) across independent terminal pairs is NP-complete via Directed Multiway Cut. Furthermore, our Co-Adaptive Stackelberg formulation incorporates heterogeneous operational disruption weights, proving that strategic chokepoint interdiction severs all paths with $54.1\%$ fewer revocations than greedy heuristics.

\subsection{Discussion and Operational Considerations}
\paragraph{Deployment in 24/7 Enterprise SOC Environments:}
CIPG is designed to operate as a low-overhead sidecar on Domain Controllers and Enterprise CAs. In our stress tests, sustained processing of $2,228.4$~events/sec consumed only $6.33$~MB RAM, ensuring zero interference with real-time domain authentication. The CA database bridge queries can be scheduled via local RPC or lightweight SQLite mirrors without imposing database locks on the primary \texttt{CertSrv} service.

\paragraph{Cloud-Hybrid Identity Extensions:}
Modern enterprises increasingly synchronize Active Directory with cloud-based Microsoft Entra ID (formerly Azure AD) via Entra Connect. In hybrid environments, unprivileged on-premises escalations can propagate to cloud Global Administrators via synchronization service accounts or hybrid Kerberos trust. Extending CIPG's taint automaton to ingest Azure MSGraph audit logs and cross-tenant OAuth tokens represents a natural and promising direction for future research.

\subsection{Conclusion}
Active Directory Certificate Services represents an indispensable yet highly vulnerable component of enterprise identity infrastructure. In this paper, we uncovered two systemic flaws in current defensive paradigms: static snapshot blindness under mutation-and-rollback attacks ($\text{SHA-256}(\mathcal{G}_{t_0}) = \text{SHA-256}(\mathcal{G}_{t_3})$), and inductive shortcut collapse in standard GNNs ($1.59\%$ accuracy on adversarial hard negatives). Furthermore, forensic analysis revealed the PKCS\#10 ASN.1 SAN concealment gap ($\pi_{\text{CA}} \cap \pi_{\text{KDC}} = \emptyset$).

We introduced \textbf{CertGraph}, a unified neuro-symbolic framework addressing these vulnerabilities across the complete attack lifecycle:
\begin{enumerate}
    \item \textbf{Multiplicative Bilinear Reachability Gating} eliminates shortcut memorization, restoring hard-negative classification accuracy to \textbf{$100.00\%$ ($63/63$)}.
    \item The \textbf{Cryptographic Invariant Provenance Graph (CIPG)} and \textbf{Invariant~V Automaton} bridge the CA--KDC logging discontinuity, achieving $100\%$ detection recall on live Windows Server 2019 attacks and $0.0\%$ false-positive rate on administrative typos, while delivering $69.04\%$ graph compression.
    \item The \textbf{Disruption-Budgeted Stackelberg Remediation Game} provides provable path interdiction (Theorem~\ref{thm:nphardness}), strictly dominating greedy heuristics ($p = 3.12 \times 10^{-5}$) and achieving $100.0\%$ path interdiction with a \textbf{54.1\% reduction in operational administrative disruption}.
\end{enumerate}
Together, these contributions demonstrate that combining reachability-gated graph neural networks, cryptographic audit provenance, and co-adaptive game theory provides a rigorous, scalable, and operationally viable defense for enterprise identity infrastructures.
