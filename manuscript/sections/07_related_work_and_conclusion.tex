\section{Related Work, Discussion, and Conclusion}
\label{sec:related_conclusion}

\subsection{Related Work}

\paragraph{Active Directory and PKI Security:}
Automated privilege escalation analysis on identity graphs originated with BloodHound~\cite{robbins2017bloodhound}, which models Windows domain objects using graph databases and Dijkstra-based shortest-path traversal. SpecterOps~\cite{specterops2021certified} expanded the attack surface to Public Key Infrastructure by formalizing certificate template misconfigurations (ESC1--ESC8), later extended through ESC13. Open-source audit tools such as Certipy~\cite{certipy2021} and Lynt automate template querying via LDAP. However, these tools operate strictly on periodic static snapshots, leaving them fundamentally blind to temporal rollback attacks ($\text{SHA-256}(\mathcal{G}_{t_0}) = \text{SHA-256}(\mathcal{G}_{t_3})$) and incapable of correlating split-actor certificate issuances with downstream Kerberos PKINIT authentications.

\paragraph{Graph Neural Networks in Cyber Defense:}
GNNs have been applied to vulnerability discovery, binary analysis, and intrusion detection~\cite{kipf2017semi,velickovic2018graph,guo2022practical,vasquez2024identity}. In access control multigraphs, however, existing architectures suffer from representation collapse and feature erasure (Theorem~\ref{thm:theorem1}). While additive skip connections preserve initial feature gradients, we showed that they induce severe inductive shortcut collapse, reducing hard-negative accuracy to $1.59\%$. CertGraph's Multiplicative Bilinear Gating provides the first formal mechanism to enforce that attribute signals cannot bypass multi-hop reachability verification.

\paragraph{Provenance Graphs and Causality Tracking:}
System provenance techniques (e.g., CamFlow~\cite{pasquier2017practical}, Unicorn~\cite{han2020unicorn}, and NodeMerge~\cite{hassan2020tactical}) track causal relationships across kernel-level system calls (processes, files, sockets). Recently, whole-network provenance analytics have been extended to identity infrastructure: HADES~\cite{liu2026hades} and CPD~\cite{liu2026cpd} pioneered whole-network Active Directory provenance via cross-machine logon session tracking and meta-node graph compression to uncover lateral movement and cyber persistence threats. However, while host- and logon-level provenance captures interactive session traversals, it operates outside the cryptographic public-key infrastructure plane. Consequently, existing approaches remain fundamentally blind to transient LDAP attribute rollbacks (\texttt{Event 5136}), PKCS\#10 ASN.1 SAN concealment, and the CA--KDC cryptographic identifier split-brain ($\pi_{\text{CA}} \cap \pi_{\text{KDC}} = \emptyset$). CIPG extends identity provenance into the PKI control plane, introducing stateful cryptographic invariants that bridge Active Directory directory modifications, the CA Jet database, and Kerberos PKINIT authentications.

\paragraph{Game-Theoretic Interdiction and Access Control Defense:}
Network interdiction models have been extensively studied in game theory and physical infrastructure defense~\cite{tambe2011security,dahlhaus1994multiterminal,garg1994multiway}. In identity security, Guo et al.~\cite{guo2022practical,guo2023scalable} analyzed shortest-path interdiction on BloodHound graphs, which was subsequently generalized to adaptive path removal~\cite{apr2025} and optimal decoy placement via Stackelberg games~\cite{ngo2024odsa}. Theorem~\ref{thm:nphardness} advances this theoretical foundation by proving that Multi-Principal Access Interdiction (MPAI) across independent terminal pairs is NP-complete via Directed Multiway Cut. Furthermore, as emphasized in recent Active Directory interdiction literature~\cite{apr2025}, real-world enterprise directories contain non-blockable, mission-critical operational dependencies ($E_b \subsetneq E$). Our Co-Adaptive Stackelberg formulation explicitly incorporates heterogeneous operational disruption weights and non-blockable dependencies, proving that strategic chokepoint interdiction severs $98.5 \pm 4.0\%$ of attack paths while revoking $45.0\%$ fewer edges than greedy heuristics ($6.0$ vs. $10.9$ edges, $p = 0.0431$), leaving an irreducible $\sim 1.5\%$ residual attack surface that must be defended at runtime by CIPG.

\subsection{Discussion and Operational Considerations}
\paragraph{Deployment in 24/7 Enterprise SOC Environments:}
CIPG is designed to operate as a low-overhead sidecar on Domain Controllers and Enterprise CAs. In our stress tests, sustained processing of $13,192.4$~events/sec consumed only $6.91$~MB RAM (evaluation latency: 771.81~ms), ensuring zero interference with real-time domain authentication. The CA database bridge queries can be scheduled via local RPC or lightweight SQLite mirrors without imposing database locks on the primary \texttt{CertSrv} service.

\paragraph{Cloud-Hybrid Identity Extensions:}
Modern enterprises increasingly synchronize Active Directory with cloud-based Microsoft Entra ID (formerly Azure AD) via Entra Connect. In hybrid environments, unprivileged on-premises escalations can propagate to cloud Global Administrators via synchronization service accounts or hybrid Kerberos trust. Extending CIPG's taint automaton to ingest Azure MSGraph audit logs and cross-tenant OAuth tokens represents a natural and promising direction for future research.

\subsection{Threats to Validity and Limitations}
To facilitate rigorous scrutiny, we explicitly delineate three primary threats to validity and experimental limitations:
\begin{enumerate}
    \item \textbf{Live Cyber-Range Scale vs. Trace-Driven Stress Stream Synthesis:} Ground-truth protocol mechanics and cross-host schema discontinuities ($\pi_{\text{CA}} \cap \pi_{\text{KDC}} = \emptyset$) were established empirically across seven live multi-stage attack and rollback campaigns (473 raw XML security events and 24 CA Jet Database rows) executed on genuine Windows Server 2019 Domain Controller (\texttt{DC03}) and Enterprise CA (\texttt{SRV03}) virtual machines within the Game of Active Directory cyber-range. While these live deployments guarantee exact operating system and logging fidelity, the $10,182$-event concurrency benchmark is a trace-driven synthetic stream combining these genuine schema traces with high-volume Poisson background renewals ($\lambda = 2,000/\text{hr}$) and routine interactive logons ($n = 7,950$). Evaluating CIPG under full multi-thousand-workstation physical network tap telemetry remains an operational objective.
    \item \textbf{Canonical Subgraph Abstraction in GNN Gating Ablations:} Our clean two-layer matrix GNN gating evaluations were conducted over 11-node canonical subgraphs representing the 63 counterfactual hard-negative configurations across horizons up to $h = 4$. While this abstraction cleanly demonstrates that Multiplicative Bilinear Gating eliminates inductive shortcut collapse across direct and bounded multi-hop reachability paths, enterprise directories exhibit arbitrary and unbounded group nesting depths ($h > 10$). This structural limitation directly validates our two-tier hybrid design: continuous GNN message passing acts as a fast linear screener, while deterministic symbolic path verification resolves arbitrary-depth relational crosstalk.
    \item \textbf{Parametric Disruption Costs vs. Interactive Administrator Feedback:} In our Stackelberg remediation game, operational disruption costs $c(e)$ are assigned parametrically according to relation type ($c(\text{MemberOf}) = 8.0, c(\text{GenericAll}) = 3.0$) and operational edge immutability constraints ($E_b \subsetneq E$). In production enterprise deployments, operational criticality is context-sensitive and evolving. While our formulation guarantees provable path neutralization bounds under static disruption models, integrating real-time human-in-the-loop preference elicitation~\cite{apr2025} represents a fruitful path for future enhancement.
\end{enumerate}

\subsection{Conclusion}
Active Directory Certificate Services represents an indispensable yet highly vulnerable component of enterprise identity infrastructure. In this paper, we uncovered two systemic flaws in current defensive paradigms: static snapshot blindness under mutation-and-rollback attacks ($\text{SHA-256}(\mathcal{G}_{t_0}) = \text{SHA-256}(\mathcal{G}_{t_3})$), and inductive shortcut collapse in standard GNNs ($0.00\%$ accuracy on adversarial hard negatives). Furthermore, forensic analysis revealed the PKCS\#10 ASN.1 SAN concealment gap ($\pi_{\text{CA}} \cap \pi_{\text{KDC}} = \emptyset$).

We introduced \textbf{CertGraph}, a unified neuro-symbolic framework addressing these vulnerabilities across the complete attack lifecycle:
\begin{enumerate}
    \item \textbf{Multiplicative Bilinear Reachability Gating} eliminates shortcut memorization, elevating hard-negative classification accuracy from $0.00\%$ to \textbf{$65.08\%$ ($41/63$, $95\%$ Wilson CI: $[52.8\%, 75.7\%]$)} ($1.000$ clean F1), with the remaining $34.92\%$ multi-attribute semantic crosstalk edge cases resolved to $100\%$ precision by Tier-2 symbolic verification.
    \item The \textbf{Cryptographic Invariant Provenance Graph (CIPG)} and \textbf{Invariant~V Automaton} bridge the CA--KDC logging discontinuity, detecting 7/7 live cyber-range attacks and achieving \textbf{$97.92\%$--$100.00\%$ recall, $92.16\%$--$92.31\%$ precision ($94.95\%$--$96.00\%$ F1-score)}, and an $8.00\%$ false-positive rate across 50 admin maintenance windows ($0.0395\%$ overall event FPR) under a $10,182$-event enterprise concurrent stream, while delivering $76.61\%$ meta-node graph compression at $13,192.4$~events/sec.
    \item The \textbf{Disruption-Budgeted Stackelberg Remediation Game} provides provable path interdiction (Theorem~\ref{thm:nphardness}), strictly dominating greedy heuristics across operational budgets ($p = 0.0431$). Under realistic operational edge immutability ($E_b \subsetneq E$), proactive interdiction neutralizes \textbf{$98.5\% \pm 4.0\%$} of paths at $B_{\text{ops}}=24$ with a \textbf{$45.0\%$ reduction in administrative disruption} ($6.0$ vs. $10.9$ edges), leaving an irreducible residual surface that is continuously defended at runtime by CIPG, with CIPG provenance-cone guidance delivering a \textbf{$1,246.3\times$ min-cut speedup} at $N=5,000$ nodes.
\end{enumerate}
Together, these contributions demonstrate that combining reachability-gated graph neural networks, cryptographic audit provenance, and co-adaptive game theory provides a rigorous, scalable, and operationally viable defense for enterprise identity infrastructures.
