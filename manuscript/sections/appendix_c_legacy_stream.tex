\subsection{Graph Reduction and Meta-Node Compacting}
Repeated authentication observations can make a provenance graph costly to retain and query. The legacy CIPG implementation groups repeated events into meta-nodes:
\begin{equation}
\fitmath{\mathcal{C}: (v_{\text{event}}^{(1)}, v_{\text{event}}^{(2)}, \dots, v_{\text{event}}^{(m)}) \mapsto \mathcal{V}_{\text{meta}}}
\end{equation}
Whenever repetitive, non-mutating events share identical source principals, destination templates, and access control rights within a sliding window, CIPG collapses them into a single directed meta-edge annotated with frequency counters and temporal bounding intervals $[t_{\min}, t_{\max}]$. As quantified in Section~\ref{sec:evaluation}, this reduces graph storage overhead by \textbf{76.61\%} (compressing 10,182 raw elements to 2,382 compressed elements) in the legacy implementation. Its reported $6.91$~MB and $13,192.4$~events/second do not characterize the current reference. Preservation of all identity, contradiction and revision queries under this compression has not been established; the current correctness reference retains its observations.

\paragraph{Collection delay and attribution trade-offs}
As documented in Table~\ref{tab:cipg_stress} and Table~\ref{tab:sensitivity_matrix}, in the configured synthetic CA/KDC workload, operational performance is governed by two orthogonal systems dimensions:
\begin{itemize}
    \item \textbf{Correlation Horizon ($\Delta t$) vs. False Positives:} The seeded generator places a fixed 2,000 renewal arrivals uniformly over the simulated duration $T$. A renewal chooses one of 15 maintenance templates with probability $0.055$, uniformly among them; otherwise it chooses the machine template. It does not implement an unconditional 2,000-per-hour Poisson process. For a particular maintenance template and $\Delta\le T$, the matching-arrival probability before additional principal or detector conditions is $1-(1-0.055\Delta/(15T))^{2000}$. Thus the total renewal count is not the matching-event rate. The 50 generated maintenance windows have durations in $[10,35]$~s. The saved sensitivity query observes 0/50 false alarms at 10~s, 3/50 at 30~s and 4/50 from 60~s onward. These are finite seeded-workload outcomes, not a general collision-free guarantee. The naive rollback monitor flags all 50 maintenance windows. Table~\ref{tab:sensitivity_matrix} retains the observed precision and recall values.
    \item \textbf{CA Database Polling Lag ($\Delta_{\text{poll}}$) vs. False Negatives:} The selected 4887 and 4768 fields lack a shared strong certificate key; the evaluated pipeline uses CA database enrichment to bridge them. When an attacker's PKINIT execution delay $\delta_{\text{pkinit}} \sim \text{LogNormal}(1.2, 0.8)$ executes before the next polling tick ($t_{\text{auth}} + \Delta_{\text{watermark}} < t_{\text{poll}}$), the join keys remain un-enriched at evaluation time, generating organic False Negatives. At $\Delta_{\text{poll}} = 1.0\text{s}$, CIPG achieves $100.00\%$ recall ($48/48$). At default $\Delta_{\text{poll}} = 5.0\text{s}$, CIPG achieves $97.92\%$ recall ($47/48$). At $\Delta_{\text{poll}} \in \{15\text{s}, 60\text{s}\}$, rapid attacks beat the polling cycle, resulting in $89.58\%$ recall ($43/48$).
\end{itemize}

\paragraph{Ingestion Throughput and Memory Profiling}
Under continuous streaming load:
\begin{itemize}
    \item \textbf{Throughput:} The saved legacy benchmark reports \textbf{13,192.4 events/second} (771.81~ms) on the configured synthetic stream. This excludes a demonstrated end-to-end Windows collection/deployment pipeline and is not a throughput measurement of the new reference reasoners.
    \item \textbf{Memory Footprint:} The earlier result reports \textbf{6.91 MB}. A finite-run measurement does not establish bounded retained memory as the certificate history grows.
    \item \textbf{Meta-Node Compression:} Meta-node compacting collapsed 10,182 raw elements into 2,382 compressed elements, achieving a \textbf{76.61\% reduction in graph size} without loss of topological taint information.
\end{itemize}
