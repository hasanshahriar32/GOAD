\section{Empirical Evaluation and Live Cyber-Range Benchmarks}
\label{sec:evaluation}

We conduct an empirical evaluation to validate CertGraph's static gating, dynamic provenance tracking, and game-theoretic interdiction. Specifically, we address four core research questions:
\begin{itemize}
    \item \textbf{RQ1 (Inductive Shortcut Cure):} Does Multiplicative Bilinear Gating eliminate shortcut memorization and prevent accuracy collapse on adversarial hard negatives?
    \item \textbf{RQ2 (Live Provenance Accuracy):} Can Invariant~V detect rollback, split-actor, and dormant PKINIT attacks on live Windows Server 2019 VMs without generating false alarms on benign administrator errors?
    \item \textbf{RQ3 (Provenance Scalability):} Does meta-node compacting maintain bounded memory footprint and high throughput under high-velocity audit telemetry?
    \item \textbf{RQ4 (Operational Interdiction Efficiency):} Does the Co-Adaptive Stackelberg policy achieve superior path interdiction while minimizing administrative disruption compared to industrial greedy heuristics?
\end{itemize}

\subsection{Experimental Setup}
\paragraph{Synthetic Identity Graphs:} We synthesized 700 realistic enterprise Active Directory multigraphs ranging from 500 to 10,000 security principals with realistic edge distributions calibrated against real enterprise BloodHound datasets~\cite{robbins2017bloodhound}. The dataset exhibits severe class imbalance (96\% benign, 4\% vulnerable escalation chains), mirroring real-world conditions.

\paragraph{Live Cyber-Range Cyberbed:} To evaluate live execution, we deployed an enterprise testbed on a virtualized Game of Active Directory (GOAD) cyber-range. The testbed comprises two Windows Server 2019 nodes:
\begin{itemize}
    \item \texttt{DC03} (\texttt{essos.local}): Active Directory Domain Controller, Kerberos KDC, and LDAP directory.
    \item \texttt{SRV03} (\texttt{essos-ca.essos.local}): Enterprise Subordinate Certificate Authority running Microsoft Active Directory Certificate Services.
\end{itemize}
All attacks were executed by unprivileged domain accounts (\texttt{ESSOS\textbackslash khal.drogo} and \texttt{ESSOS\textbackslash viserys.targaryen}) using headless non-interactive exploitation pipelines without GUI dependencies.

\paragraph{Failure-Mode Breakdown on GNN Hard Negatives:}
Detailed inspection of the 63 hard negatives reveals how topological gating and symbolic verification partition the problem:
\begin{enumerate}
    \item \textbf{Resolved by Reachability Gating (41 cases):} \texttt{CertGraph-Gated} successfully resolves Admin-Only Enrollment (18/18), Explicit-Deny Overrides (10/10), Horizon Nesting (10/10), and Disabled Templates (3/3), correctly closing the reachability gate when low-privilege principals lack topological access.
    \item \textbf{Multi-Attribute Semantic Crosstalk (22 cases):} In scenarios involving Low-Privilege OID Group Links (15 cases) and Unenrollable CAs (7 cases), reachability exists in the topological graph, but the vulnerability is neutralized by multi-attribute policy interactions. Continuous 2-layer matrix multiplication cannot disentangle these non-linear attribute intersections.
\end{enumerate}
Crucially, this exact $34.92\%$ neural residual ($22/63$) is why our \textbf{Tier-2 Neuro-Symbolic Verification} pipeline is strictly required: by executing an exact backward symbolic reachability traversal and attribute verification on GNN-flagged candidates, the hybrid framework eliminates all 22 misclassifications, achieving $100.00\%$ precision without manual heuristics.

\paragraph{Enterprise Concurrency Mechanics and Sensitivity Trade-Offs:}
As documented in Table~\ref{tab:cipg_stress} and Table~\ref{tab:sensitivity_matrix}, under strict Windows Server 2019 event schema fidelity ($\pi_{\text{CA}}(e_{4887}) \cap \pi_{\text{KDC}}(e_{4768}) = \emptyset$), operational performance is governed by two orthogonal systems dimensions:
\begin{itemize}
    \item \textbf{Correlation Horizon ($\Delta t$) vs. False Positives:} During 50 simulated administrator maintenance windows ($\Delta t \in [10\text{s}, 45\text{s}]$), background \texttt{AutoEnroll} requests arrived concurrently inside the mutation window with probability $1 - e^{-\lambda \Delta t}$. At $\Delta t = 10\text{s}$, zero collisions occur ($0.0\%$ FPR, $100.0\%$ precision). Widening $\Delta t$ to $30\text{s}$ admits 3 Poisson collisions ($6.0\%$ FPR). For $\Delta t \ge 60\text{s}$, false positives plateau at exactly 4 / 50 ($8.00\%$ maintenance window FPR, $0.0395\%$ overall event FPR, $92.16\%$ precision at $\Delta_{\text{poll}}=5\text{s}$ and $92.31\%$ at $\Delta_{\text{poll}}=1\text{s}$) because all 50 administrative maintenance windows conclude within $45\text{s} < 60\text{s}$. Naive rollback monitors generated 50/50 false alarms ($100\%$ FPR, $19.35\%$ precision).
    \item \textbf{CA Database Polling Lag ($\Delta_{\text{poll}}$) vs. False Negatives:} Because KDC Event 4768 omits SubjectKeyIdentifier (SKID), linking Event 4887 to Event 4768 strictly requires CA Jet DB enrichment. When an attacker's PKINIT execution delay $\delta_{\text{pkinit}} \sim \text{LogNormal}(1.2, 0.8)$ executes before the next polling tick ($t_{\text{auth}} + \Delta_{\text{watermark}} < t_{\text{poll}}$), the join keys remain un-enriched at evaluation time, generating organic False Negatives. At $\Delta_{\text{poll}} = 1.0\text{s}$, CIPG achieves $100.00\%$ recall ($48/48$). At default $\Delta_{\text{poll}} = 5.0\text{s}$, CIPG achieves $97.92\%$ recall ($47/48$). At $\Delta_{\text{poll}} \in \{15\text{s}, 60\text{s}\}$, rapid attacks beat the polling cycle, resulting in $89.58\%$ recall ($43/48$).
\end{itemize}

\subsection{RQ4: Game-Theoretic Stackelberg Remediation Performance}
We evaluated our Co-Adaptive Stackelberg policy against three standard remediation baselines across 30 realistic enterprise multi-forest topologies:
\begin{enumerate}
    \item \textbf{Random Cut:} Selects arbitrary reachable edges within budget.
    \item \textbf{Degree Centrality:} Selects edges incident to the highest-degree nodes.
    \item \textbf{Static Greedy:} Iteratively severs the edge participating in the greatest number of remaining shortest attack paths.
    \item \textbf{Co-Adaptive Stackelberg (Ours):} Solves the bilevel interdiction game under heterogeneous operational disruption costs and operational edge immutability ($E_b \subsetneq E$).
\end{enumerate}

\paragraph{Operational Immutability Plateau and the Runtime Defense Residual:}
In enterprise networks, a realistic fraction of directory edges represents immutable operational dependencies ($E_b \subsetneq E$). As shown in Table~\ref{tab:stackelberg_results}, proactive graph interdiction achieves \textbf{$98.5 \pm 4.0\%$} paths severed at $B_{\text{ops}}=24$ (vs. $97.6 \pm 6.5\%$ for Static Greedy).
This proves a critical scientific insight: \textit{proactive graph hardening alone can never achieve 100\% security in a living enterprise without breaking mission-critical legacy dependencies}. The resulting $\sim 1.5\%$ residual attack surface strictly necessitates the runtime monitoring provided by CIPG.

\paragraph{45.0\% Reduction in Administrative Disruption:}
Under $B_{\text{ops}} = 24$, Static Greedy revokes an average of \textbf{10.9 edges} ($10.9 \pm 0.9$), predominantly cutting high-cost \texttt{MemberOf} delegations that disrupt user workflows. In contrast, Co-Adaptive Stackelberg revokes an average of only \textbf{6.0 edges} ($6.0 \pm 2.6$) by targeting CA template chokepoints—a \textbf{45.0\% reduction in administrative disruption}.
