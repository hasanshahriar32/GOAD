\begin{abstract}
\noindent Active Directory Certificate Services (ADCS) exposes a difficult attribution problem when transient configuration changes precede certificate use and issuance and authentication records lack shared certificate identifiers. We develop CertGraph, combining a static graph model, Cryptographic Invariant Provenance Graph (CIPG), and disruption-budgeted interdiction. An issuer-scoped constraint reference reports revisable definite, possible, and conflicting lineages. In a frozen synthetic confirmation, it retains 99.06 percent of true observed links as candidates and resolves 55.82 percent definitively. It returns 107 correct and zero false definite mutation overlaps, compared with 310 correct and 51 false overlaps for a point-time comparator. Paired intervention matrices in Windows 2016 and an independently provisioned Windows 2019 forest validate 24 exact-certificate authentication outcomes, including six administrative uses, while actual Certipy and Sigma executions identify configuration risk separately from successful privilege escalation. Controlled operation order supplies an additional evidence channel without repairing an inconsistent audit-clock model. Static-model audits identify augmentation confounding and repeated training archetypes. A separate literal bilinear implementation reproduces 10,800 held-out checkpoint predictions on family-disjoint inputs, with matched initialization and augmentation. It has no classification advantage over additive attention and misses reachable long paths, motivating explicit symbolic treatment of unresolved cases. Finally, we formulate multi-principal interdiction, relate its hardness to directed multiway cut, and evaluate remediation under assigned disruption costs. The contribution is a reproducible integration of certificate-specific evidence contracts, controlled interventions, and uncertainty-aware attribution, with measured trade-offs rather than universal detection or operational guarantees.
\end{abstract}
