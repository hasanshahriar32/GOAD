\begin{abstract}
\noindent Active Directory Certificate Services (ADCS) forms the identity backbone of enterprise Windows networks, but access-control misconfigurations enable catastrophic privilege escalation. Existing defenses suffer from static snapshot blindness, where temporal template mutations leave bit-identical pre-attack and post-rollback directory snapshots, and inductive shortcut collapse, where standard graph neural networks memorize template configuration flags and achieve zero percent accuracy under adversarial counterfactual hard negatives. Furthermore, audit log inspection reveals disjoint cryptographic identifier schemas between Certification Authority issuance logs and Domain Controller authentication logs. We introduce CertGraph, an integrated static-to-dynamic neuro-symbolic framework for escalation detection and autonomous interdiction. Multiplicative bilinear reachability gating conditions message-passing on authorization reachability, elevating hard-negative accuracy to 65.08 percent with residual cases resolved by symbolic verification. At runtime, the Cryptographic Invariant Provenance Graph (CIPG) bridges cross-host logging discontinuities via continuous database correlation, achieving 97.92 to 100.00 percent recall, 92.16 to 92.31 percent precision, and an 8.00 percent maintenance window false-positive rate under concurrent enterprise traffic at 13,192 events per second. Finally, we model access revocation as a disruption-budgeted Stackelberg game, prove multi-principal interdiction is NP-complete, and demonstrate a co-adaptive policy that neutralizes 98.5 percent of attack paths with 45.0 percent less disruption and a 1,246-fold provenance-cone acceleration.
\end{abstract}
