We are pleased to submit our original research manuscript titled "CertGraph: Neuro-Symbolic Defense and Cryptographic Provenance for Enterprise Public-Key Infrastructure" for consideration for publication as a regular research article in Computers & Security.

Active Directory Certificate Services (ADCS) forms the identity and public-key infrastructure (PKI) backbone of modern enterprise Windows domains, issuing cryptographic credentials for single sign-on, smartcard logon, and code signing. However, structural misconfigurations in certificate templates and enrollment access control lists (ACLs) introduce critical privilege escalation vectors that allow unprivileged domain users to compromise enterprise root domain controllers.

Current defensive systems suffer from three fundamental blind spots:
1. Static Snapshot Blindness: Adversaries leverage temporal mutation-and-rollback techniques (e.g., ESC4, ESC9) that leave the directory in a bit-identical pre-attack and post-rollback state, rendering static scanners (e.g., BloodHound, Certipy) completely blind to post-rollback credential abuse.
2. Inductive Shortcut Memorization in GNNs: Standard message-passing graph neural networks memorize local template attribute flags, collapsing to 0.00% accuracy under adversarial counterfactual hard negatives.
3. CA-KDC Schema Discontinuity: In Windows Server 2019, Certification Authority (CA) issuance logs (Event ID 4887) and Domain Controller Kerberos PKINIT authentication logs (Event ID 4768) share zero common event identifiers, allowing PKCS#10 ASN.1 Subject Alternative Name (SAN) concealment attacks to remain undetected across single-host monitors.

In this work, we present CertGraph, an integrated static-to-dynamic neuro-symbolic framework addressing these challenges:
- We formulate the Multiplicative Bilinear Reachability Gate, which conditions GNN message passing on topological authorization reachability, eliminating inductive shortcut collapse and elevating hard-negative accuracy from 0.00% to 65.08%, with residual semantic crosstalk cases resolved to 100% precision via Tier-2 symbolic verification.
- We engineer the Cryptographic Invariant Provenance Graph (CIPG), an asynchronous state-tracking automaton that bridges CA transactional records and KDC event streams. On a 10,182-event enterprise concurrency stream and live Windows Server 2019 cyber-range testbed, CIPG detects 7/7 live attacks and achieves 97.92% to 100.00% recall, 92.16% to 92.31% precision, and an 8.00% maintenance window false-positive rate (0.0395% overall event FPR) under sustained throughput exceeding 13,000 events/second.
- We model proactive privilege revocation as a disruption-budgeted Stackelberg game, prove that Multi-Principal Access Interdiction (MPAI) is NP-complete via reduction from Directed Multiway Cut, and validate a co-adaptive remediation policy that neutralizes 98.5% of attack paths under operational edge immutability with 45.0% lower administrative disruption, accelerated 1,246-fold by CIPG provenance-cone guidance.
