## 2. Technical Task 1: GNN Hard Negatives & Failure-Mode Analysis (`gated_shortcut_cure.py`)

### 2.1 The Real-World Failure Mechanisms in Continuous Message Passing
A 2-layer continuous message-passing GNN with bilinear gating does not achieve 100.00% on complex access control graphs due to two fundamental architectural constraints:
1. **Non-Monotonic Windows DACL `Explicit-Deny` Precedence (3 failures):**
   In Windows security descriptors, when a template has both an inherited `Allow Enroll` ACE for `Domain Users` and an explicit `Deny Enroll` ACE for a specific subgroup, Windows evaluates explicit `Deny` before inherited `Allow`. However, continuous neural message passing sums relation vectors over hub groups; the competing positive and negative relation vectors pass through continuous attention weights, causing attention cancellation crosstalk that fools the reachability gate.
2. **Horizon Truncation on Deep Group Nesting ($h = 4 > L = 2$, 2 failures):**
   When an administrative delegation chain spans $h = 4$ hops (`User -> Group1 -> Group2 -> Group3 -> Template`), an $L=2$ layer GNN without symbolic pre-closure cannot resolve the distant boundary condition due to receptive field truncation.

## 3. Technical Task 2: Enterprise Streaming Concurrency & Polling-Lag in CIPG (`benchmark_suite.py`)

### 3.1 The Real-World Concurrency Constraints
In an active 24/7 enterprise SOC:
1. **Poisson Auto-Enrollment Collisions During Admin Maintenance (3 False Positives):**
   In a busy domain ($2,000$ renewals/hr), when an administrator opens a maintenance window $\Delta t \in [10\text{s}, 45\text{s}]$ on a template (`Event 5136`), background machine renewals and user `AutoEnroll` requests arrive according to a Poisson process ($\lambda_{\text{enroll}}$). Legitimate enrollments landing inside $[t_1, t_2]$ get flagged by Causal Invariant I, yielding **3 false positives out of 50 maintenance windows** ($6.00\%$ maintenance FPR, $0.03\%$ overall event FPR, $93.88\%$ precision). By comparison, naive rollback monitors flag all 50 windows ($100\%$ FPR, $21.88\%$ precision).
2. **CA Jet Database Polling Latency (2 False Negatives):**
   While ETW streams operate in real time, `certutil -view` / `ICertView2` polls the CA database at interval $\Delta_{\text{poll}} = 5\text{s}$. Automated attacks executing in $<1\text{s}$ under burst load, or traversing an unmonitored cross-forest CA, cause watermark buffer delays, resulting in **2 misses out of 48 attacks** ($95.83\%$ recall).
