## 3. Task 2: Solving the GNN Shortcut Collapse via Multiplicative Reachability Gating (`CertGraph-Gated`)

### 3.1 Mathematical Diagnosis of Additive Shortcut Collapse
In vanilla Graph Neural Networks (including `CertGraph-Additive`), residual skip updates are additive:
$$\tilde{h}_t^{(l)} = \operatorname{ReLU}\left(W_{\text{skip}}^{(l)} h_t^{(l-1)} + \mu_t^{(l)}\right)$$
Because $W_{\text{skip}}$ creates a direct linear pathway from input template features $x_{\text{Template}}$ to the output logits, gradient descent optimizes the single-layer feature pathway while ignoring multi-hop reachability message passing $\mu_t^{(l)}$. When evaluated on zero-shot hard negatives (dangerous flags active, but inbound enrollment edges restricted to Tier-0), `CertGraph-Additive` collapsed to **$0.00\%$ accuracy ($0/63$)**.

### 3.2 Proposed Cure: Bilinear Reachability Gating + Counterfactual Edge-Drop
We implemented `CertGraph-Gated` in [`thesis_research/src/phase2_certgraph/gated_shortcut_cure.py`](file:///home/m4x1d/Desktop/GOAD/thesis_research/src/phase2_certgraph/gated_shortcut_cure.py):
$$\tilde{h}_t^{(l)} = \left(W_{\text{skip}}^{(l)} h_t^{(l-1)}\right) \odot \sigma\left(W_{\text{gate}}^{(l)} \mu_{t,\text{lowpriv\_inbound}}^{(l)} + b_{\text{gate}}\right)$$
coupled with **Counterfactual Edge-Drop Augmentation** ($p_{\text{cf}} = 0.3$), where for 30% of positive training templates, inbound low-privilege `Enroll` edges are severed on-the-fly and the target label is inverted to $y = \texttt{Safe}$.

Because the gate is **multiplicative**, when low-privilege inbound messages are absent ($\mu_{\text{inbound}} = \mathbf{0}$):
$$\text{Gate} = \sigma(b_{\text{gate}}) \approx \mathbf{0} \implies \lim_{\mu_{\text{inbound}} \to \mathbf{0}} \tilde{h}_t^{(l)} = \mathbf{0}$$
The gate multiplicatively extinguishes the feature bypass, rendering it mathematically impossible for the classification head to inspect template configuration bits without verified topological reachability.
